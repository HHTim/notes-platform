# 選字問 AI 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在日文、英文模組裡選一段字就能在網站內問 Gemini（免費版），並讓 `ask-ai` 分支可以單獨上線。

**Architecture:** 新增一支不用框架的 `builder/templates/askai.js`：上半是純函式（濾讀音、組問題、顯示回答、錯誤分類，node 可測），下半是瀏覽器部分（選字按鈕、對話框、第一次使用才用 `import()` 從 gstatic 載入 Firebase 新式 SDK 13.0.0 的 app、app-check、ai 三個模組）。`build.py` 依 `content/askai.json` 與 `module.json` 的 `ask_ai` 決定放不放。發佈設定改成由 repo 變數 `DEPLOY_BRANCH` 決定哪條分支上線。

**Tech Stack:** Python 3.14（建置與測試）、純 JavaScript（node 跑測試）、Firebase JS SDK 13.0.0（modular，CDN）、Firebase AI Logic＋Gemini Developer API 免費版、App Check＋reCAPTCHA Enterprise、GitHub Actions。

**Spec:** `docs/superpowers/specs/2026-10-14-ask-ai-design.md`

## Global Constraints

- 所有 AI 相關 commit 只進 `ask-ai` 分支；唯一例外是 Task 1 的發佈設定，`main` 也要有同一份（不含任何 AI 程式）。不併回 `main`。
- 不用框架、不加 npm 套件；`askai.js` 跟 `sync.js` 同樣寫法：純函式放 `var NotesAsk = {...}`，`module.exports` 給 node。
- Firebase 新式 SDK 版本固定 `13.0.0`，網址 `https://www.gstatic.com/firebasejs/13.0.0/firebase-<名稱>.js`。
- 型號 `gemini-3.8-flash`，寫在 `content/askai.json` 的 `model`。
- 選取文字上限 500 字、前後文上限 800 字。
- 回答只支援粗體、條列（`-`、`1.`）、換行、行內程式碼；先跳脫再轉格式。
- 錯誤訊息照規格表格逐字使用。
- 對話框底部固定小字：「免費版：問題與回答會被 Google 用來改進產品，不要貼個人資料。」
- 新樣式只用 `style.css` 既有的顏色變數（不新增變數）；圖示畫在 `icons.svg`，不用 emoji。
- 寫給 Tim 的文字照 `~/.claude/tim-style/RULES.md`。
- commit 身分 HHTim；結尾 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`；gh 指令前綴 `GH_TOKEN=$(gh auth token -u HHTim)`。
- 測試指令：`python3 -m unittest discover -s builder/tests`。

## Review Focus

1. **發佈互相取消**：`concurrency` 群組若兩條分支共用，`main` 的 push 會把排隊中的 `ask-ai` 發佈略過。群組要依分支分開（Task 1 的設定檔測試擋）。
2. **選取範圍切到讀音中間**：選取從 `<rt>` 裡開始或只選到讀音，取出的文字要不含讀音；只選到讀音時不出按鈕（Task 2 的 `stripReadings` 測試擋）。
3. **AI 回傳含標籤或怪格式**：`<img onerror>`、`<script>`、沒配對的 `**`、`[x](javascript:...)` 都要顯示成純文字（Task 2 的 `renderAnswer` 測試擋）。
4. **手機點按鈕時選取被清掉**：iOS 點下按鈕的瞬間選取會消失，所以要用「最後一次非空選取」而不是點擊當下的選取（Task 4 用 `?askai=mock` 在手機寬度實測）。
5. **回答還在串流時關掉對話框或換題**：晚到的片段不能寫進新的對話（Task 4 的世代編號；mock 模式實測）。

- [ ] **Step 3: 寫 `builder/templates/askai.js` 上半段**

```javascript
/* 選字問 AI（規格 docs/superpowers/specs/2026-10-14-ask-ai-design.md）。
   上半是純函式（node 測試用得到）；下半是瀏覽器部分，只有 build 放了 ASKAI_CONFIG 才跑。 */
var NotesAsk = {
  /* 選取範圍複製出來的 HTML → 純文字。日文的讀音（rt）與括號（rp）整個拿掉，
     不然「私」會變成「私わたし」送出去。選取切在讀音中間時只剩半個標籤，一樣拿掉。 */
  stripReadings: function (html) {
    var s = String(html || '')
      .replace(/<(rt|rp)\b[^>]*>[\s\S]*?<\/\1>/gi, '')
      .replace(/^[\s\S]*?<\/rt>/i, function (m) { return /<rt\b/i.test(m) ? m : ''; })   // 開頭半截：…</rt>
      .replace(/<rt\b[^>]*>[\s\S]*$/i, '')                                               // 結尾半截：<rt>…
      .replace(/<br\s*\/?>/gi, '\n')
      .replace(/<[^>]*>/g, '');
    s = s.replace(/&lt;/g, '<').replace(/&gt;/g, '>').replace(/&quot;/g, '"').replace(/&#39;/g, "'")
      .replace(/&nbsp;/g, ' ').replace(/&amp;/g, '&');
    return s.split('\n').map(function (l) { return l.replace(/[ \t　]+/g, ' ').trim(); })
      .join('\n').replace(/\n{3,}/g, '\n\n').trim();
  },
  clip: function (s, n) {
    s = String(s || '');
    return s.length > n ? { text: s.slice(0, n) + '…', cut: true } : { text: s, cut: false };
  },
  systemText: function (lang) {
    var lines = [
      '你是幫台灣學生解釋文法的老師，用繁體中文、台灣用語回答。',
      '先一句話講結論，再條列說明；不寫長段落。',
      '日文漢字後面用全形括號附讀音，例：私（わたし）。不用羅馬拼音。',
      '有不確定的地方直接說不確定，不要編。'
    ];
    if (lang === 'ja') lines.push('讀者程度：剛學完日檢 N5 文法。');
    else if (lang === 'en') lines.push('讀者在準備多益。');
    return lines.join('\n');
  },
  buildPrompt: function (c) {
    var out = [];
    if (c.module) out.push('模組：' + c.module);
    if (c.lesson) out.push('課：' + c.lesson);
    if (c.section) out.push('小節：' + c.section);
    if (c.context) out.push('前後文：' + c.context);
    out.push('我選的字：「' + (c.selected || '') + '」');
    out.push('問題：' + (c.question || ''));
    return out.join('\n');
  },
  /* AI 回的 Markdown → HTML。先把整段跳脫，AI 回什麼都不會變成標籤；只轉粗體、條列、行內程式碼、換行。 */
  renderAnswer: function (md) {
    function esc(s) { return s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;'); }
    function inline(s) {
      s = esc(s)
        .replace(/`([^`]+)`/g, '<code>$1</code>')
        .replace(/\*\*([^*]+)\*\*/g, '<b>$1</b>');
      /* 日文包 lang="ja"：連續假名，或後面帶（讀音）的漢字 */
      return s.replace(/(?:[一-鿿々]+（[぀-ヿー]+）|[぀-ヿー])+/g, '<span lang="ja">$&</span>');
    }
    var html = [], list = null, para = [];
    function flushPara() { if (para.length) { html.push('<p>' + para.join('<br>') + '</p>'); para = []; } }
    function flushList() { if (list) { html.push('<' + list.tag + '>' + list.items.join('') + '</' + list.tag + '>'); list = null; } }
    String(md || '').split('\n').forEach(function (line) {
      var m = line.match(/^\s*(?:([-*])|(\d+)\.)\s+(.*)$/);
      if (m) {
        flushPara();
        var tag = m[1] ? 'ul' : 'ol';
        if (!list || list.tag !== tag) { flushList(); list = { tag: tag, items: [] }; }
        list.items.push('<li>' + inline(m[3]) + '</li>');
      } else if (!line.trim()) {
        flushPara(); flushList();
      } else {
        flushList(); para.push(inline(line.trim()));
      }
    });
    flushPara(); flushList();
    return html.join('');
  },
  classifyError: function (err) {
    if (!err) return 'other';
    var d = err.customErrorData || {};
    var status = d.status || 0;
    var text = (err.message || '') + ' ' + JSON.stringify(d.errorDetails || '');
    if (err.code === 'response-error') return 'blocked';
    if (status === 429) return /PerDay|per day/i.test(text) ? 'quota-day' : 'quota-minute';
    if (status === 401 || status === 403 || /app ?check/i.test(text)) return 'appcheck';
    if (err.name === 'TypeError' || err.name === 'AbortError' || (err.code === 'error' && !status) ||
        (err.code === 'fetch-error' && !status)) return 'network';
    return 'other';
  },
  MESSAGES: {
    'quota-day': '今天的免費額度用完了，明天再試。',
    'quota-minute': '問太快了，等一分鐘再問。',
    'appcheck': '驗證沒通過，重新整理頁面再試。',
    'network': '連不上 AI，檢查網路後按「再試一次」。',
    'blocked': 'AI 沒有回答這題，換個問法試試。',
    'other': 'AI 暫時沒有回應，按「再試一次」。'
  }
};
if (typeof module !== 'undefined' && module.exports) { module.exports = NotesAsk; }
```

```javascript
      var k = NotesAsk.classifyError(err);
      ans.className = 'aa-err';
      ans.innerHTML = esc(NotesAsk.MESSAGES[k]) + ((k === 'network' || k === 'other') ? '<button type="button">再試一次</button>' : '');
      var rb = ans.querySelector('button');
      if (rb) rb.addEventListener('click', function () { ans.remove(); chat = null; send(q); });   // 重試開新對話，避免半截回答留在對話紀錄裡
      if (window.console) console.warn('askai', err);
    }).then(function () { if (my === gen) sendBtn.disabled = false; });
  }
})();
```

注意：
- 重試時 `chat = null` 會讓下一則送出完整的 `buildPrompt`，這是故意的（第一題失敗時 AI 那邊沒有前後文）；但第二題以後失敗重試，會丟掉前面的對話脈絡。ledger 記一筆 Ruling：「重試＝重開對話，換取不會有半截回答；代價是追問中途失敗要重講前文」。
- `async function`／`for await` 讓 `node --check` 照樣過；CI 的「檢查產出的 JavaScript 語法」也會檢查 `dist/askai.js`。
