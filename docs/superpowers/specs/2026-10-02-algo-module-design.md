## 拍板的事

1. **新開一個模組**：id `algo`，標題「資料結構與演算法」，圖示 🧮，放在面試集後面。
2. **深度**：從頭打底、講到面試夠用。每個主題先用白話與圖講清楚「它長什麼樣、為什麼這樣設計、每個操作多快」，再進面試常見題型。不寫證明，複雜度講到能自己推。
3. **語言**：範例全部用 Java（以 Java 25 為準，必要時標 21 的差異），用 JDK 內建的類別（`ArrayList`、`HashMap`、`ArrayDeque`、`PriorityQueue`、`TreeMap`……）。**每段程式碼都要實際編譯執行過**，課文寫的輸出要是實跑的結果。
4. **練習**：網站不能跑程式，所以課中練習出四選一的「看程式碼判斷」題：複雜度是多少、印出什麼、這一步之後資料結構長怎樣、該選哪種資料結構、下一步該做什麼。每課課中練習 40〜55 題、課末測驗 10 題。
5. **刷題清單**：每課最後附「動手練」清單，列 LeetCode 題號與英文題名、各考本課的哪一招、建議難度順序（每課 5〜8 題）。**只列題號與題名並連到題目頁，不抄題目敘述**（題目敘述有版權）。課中練習全部自編。
6. **圖**：陣列、鏈結串列、樹、堆積、圖都畫 inline SVG，畫法見計畫檔的範本。
