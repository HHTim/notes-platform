# 網站改版與錯題區 設計規格

- 日期：2026-10-13
- 狀態：設計已與 Tim 用示意圖逐題確認完畢，待實作
- 範圍：只動 `builder/`（樣板與建置工具）與 `content/modules.json` 的圖示欄位。**課文與題目內容檔一律不動。**
- 本規格取代 2026-09-04 總規格第 5 節的「風格」段（色系與圖示），其他段落照舊。

## 1. 目的

Tim 對現站的五個不滿：課文讀起來累、測驗回饋太平、看膩了想換風格、手機上不好用、emoji 圖示太像 AI 做的。另外提出一個新功能：錯題區，把答錯的題目集中反覆練。

成功的樣子：同一批內容檔不改一個字，建置出來的網站換成下面描述的樣子，手機和電腦都能用，進度與錯題跨裝置同步。

## 2. 外觀

### 2.1 色系（取代舊的奶油底／古銅／灰藍）

| 用途 | 色號 |
|---|---|
| 頁面底、卡片底 | 白 #FFFFFF |
| 墨色（所有文字、深色按鈕） | 深綠灰 #233831 |
| 次要文字（小字、說明） | #5A6B65 |
| 底塊（目錄框、標籤、進度條底、選項圓圈） | #DEE5DD |
| 正確（答對的選項底、全完成的卡） | 薄荷 #C5E0D7，邊線 #A9D9C7 |
| 頂欄下緣線 | #A9D9C7 |
| 錯誤（選錯的選項底、錯題數字標籤） | 桃 #F2CEAE，邊線 #F29F80 |
| 小節標記、解說左邊線 | #FBC580 |
| 圈叉圖示 | 綠圈 #1F8A5B、紅叉 #D9603A |

原則：顏色只當「記號」，不當背景。內容區永遠白底。六個淡色都不能當字的顏色，字一律用墨色。**維持不做深色模式。**

### 2.2 字與形狀

- 字體：思源黑體（Noto Sans TC）。數字、成績用等寬字（JetBrains Mono）。拿掉 Chivo。
- 圓角卡片（10〜12px）、1.5px 細邊框、不用陰影。
- 按鈕：膠囊形。主要按鈕墨色底白字，次要按鈕白底墨色邊。

### 2.3 圖示

- 全部換成自己畫的 SVG，畫法「粗線加色」：線寬 2.4、圓端、墨色；每顆圖示挑一塊面填桃色 #FBC580 或薄荷 #A9D9C7。
- 11 個模組各一顆，存在 `builder/templates/icons.svg`（一個檔，每顆是一個 `<symbol id="…">`），建置時整包內嵌進每一頁。
- `content/modules.json` 的 `icon` 欄位從 emoji 改成圖示名稱（例如 `"java"`）。建置時名稱對不到 symbol 就報錯停止。
- 版面上的小圖示（選單、圈、叉、半圓、勾）同一個檔、同一種畫法。頁面裡不再出現任何 emoji。

## 3. 課文頁

### 3.1 本課小節目錄（建置時自動產生）

- 來源：每課 `lesson.html` 裡的 `<h3 class="head">`，建置時依序補上 `id="sec-1"`、`sec-2`……，並在課文後面固定加兩項「課中練習」（有 `.drill` 才加）與「隨堂測驗」。
- 手機（寬度 900px 以下）：目錄是課文開頭的一塊，#DEE5DD 底、可收合，預設展開。
- 電腦：目錄併進左側欄，只在**目前這課**的側欄項目底下展開小節，縮排顯示；讀到哪一節，該小節標橘線（#F29F80）。捲動時用瀏覽器的 IntersectionObserver（監看元素有沒有進入畫面的內建功能）更新。
- 課首區塊維持：課名、「第 N 課 / 共 M 課」「約 N 分鐘」兩個標籤、一句簡介。

### 3.2 左側欄

由上到下：

1. 總覽
2. 錯題區（右邊桃色數字＝目前題數；0 題時數字不顯示）
3. 課程清單（有分組就顯示分組標題）。每課右邊：全對顯示綠勾；做過但沒全對顯示最佳成績「5/8」；沒做過顯示「–」。

手機上側欄還是從左邊滑出的抽屜，行為不變。

### 3.3 課中練習

作答方式不變（點一個馬上看對錯，不計分、不記錄）。外觀改成與隨堂測驗同一套：正解薄荷底加綠圈、選錯桃底加紅叉、解說黃色左邊線。

## 4. 隨堂測驗

### 4.1 作答（不變）

整課全部選好才按「對答案」。選項順序每次重排。選項前面標 A、B、C、D（依重排後的順序）。

### 4.2 對完答案

畫面捲到測驗區頂端，由上到下：

1. **成績卡**（#DEE5DD 底）：大數字「5 / 8」、薄荷進度條、一行小字「最佳 5/8」。沒有「答對幾題、比上次多幾題」這類文字。
2. **兩顆按鈕**：「只重做錯的 N 題」（主要）、「全部重做」（次要）。全對時只剩「全部重做」。
3. **每題照原順序**：題目卡標題列右邊一個綠圈或紅叉；正解選項薄荷底加綠圈；你選錯的選項桃底加紅叉；其他選項白底；錯的題目底下顯示解說（黃色左邊線）。對的題目也顯示解說。
4. 不再出現「正解」「你的答案」文字標籤。

### 4.3 只重做錯的

錯的題目清空、選項重排、可重選；對的題目保持已批改的樣子不能動；按鈕變回「對答案」；成績卡小字加「· 重做 N 題中」。對完之後成績以 8 題全部的結果計算（保留的對題算對）。

### 4.4 紀錄

每課維持 `{best, total, done}`，全對才 `done`。另外答錯的題目寫進錯題區（第 5 節）。

## 5. 錯題區

### 5.1 規則

- **一個模組一份**，網址 `#/wrong`，從側欄「錯題區」進入。
- **進**：隨堂測驗（含重做）答錯的題目。課中練習不收。
- **出**：在錯題區練習中**連續答對兩次**自動移除；或清單上手動按「移除」。在隨堂測驗裡答對不算。
- 同一題再答錯：連對次數歸零，題目留著。

### 5.2 清單頁

由上到下：標題「錯題區」加桃色題數標籤；一句說明「課末測驗答錯的題目會收在這裡。連續答對兩次自動移除，也可以手動移除。」；圖例列（#F7F9F6 底）：空圈「還沒對過」、半圓「對過一次」；「開始練習（N 題）」主要按鈕；題目清單依課分組（分組標題＝課名），每題左邊空圈或半圓、中間題目文字、右邊「移除」。

0 題時：說明改成「目前沒有錯題。」，不顯示按鈕與圖例。

### 5.3 練習頁

- 全部錯題一次列出（最多依現況一模組 23 課 × 10 題，實際遠少於此，不分頁）。每題標題列右邊小字寫出自哪一課；作答、對答案、對完畫面與隨堂測驗完全一樣（成績卡、圈叉、解說）。按鈕只有「對答案」，對完變「回錯題區」。
- 對完：答對的題目連對次數加一（到二就移除），答錯的歸零。

### 5.4 資料

每個模組的進度物件（現在是 `{ 課slug: {best,total,done} }`）新增兩個保留鍵，鍵名以底線開頭，不會跟課的 slug（只允許小寫字母、數字、連字號）撞到：

```
_last:  { slug: "03-grammar-sentence", at: 1791853439 }      // 最後打開的課、時間（秒）
_wrong: {
  "03-grammar-sentence|2|k3f9ab": { streak: 1, removed: 0, at: 1791853439 },
  …
}
```

- 錯題的鍵＝`課slug|題目序號|題目文字指紋`。指紋＝題目文字經 FNV-1a 32 位元雜湊（一種把任意文字算成固定長度代碼的簡單算法）後轉 36 進位、取 6 碼。題目文字改過，指紋就不同，舊紀錄對不到題目，建置後自動視為不存在（清單不列、題數不算）。
- `streak`：連對次數（0 或 1；到 2 視同移除）。`removed`：手動移除或連對兩次的時間，0 表示還在。`at`：這筆最後更動的時間。
- 「還在錯題區」＝對得到題目、`removed` 為 0、`streak` 小於 2。
- 移除的紀錄保留不刪（當作墓碑，避免舊裝置把它加回來）。

### 5.5 同步合併規則

在原本「勾過就算勾過、成績取較好」之上加兩條：

- `_last`：`at` 較新的一邊贏。
- `_wrong`：以鍵取聯集；同一鍵兩邊都有時，`at` 較新的一筆整筆贏。

Firestore 規則與文件結構不變（還是 `progress/<uid>` 一份，裡面每個模組一個物件）。

## 6. 首頁

- 頂欄：選單鈕（手機）、站名、右邊登入狀態（不變）。
- **「繼續上次」卡**（桃 #F2CEAE 底）：圖示、「繼續上次：英文」、課名一行、右邊「接著讀」膠囊鈕，連到 `<模組>/#/lesson/<slug>`。資料取各模組 `_last` 裡 `at` 最新的一筆；沒有任何紀錄就不顯示這張卡。
- **模組卡片格**：每張卡：圖示、模組名、薄荷進度條、等寬小字「完成 6 / 18 課」。全完成的卡薄荷底、進度條桃色。電腦三欄、平板兩欄、手機兩欄。
- 側欄：模組清單，每項前面小圖示（同一顆，縮小）。
- 拿掉站名下面那段長介紹，改成一句：「每個模組是一個課程站：側欄選課、課末測驗、全對打勾。」

## 7. 手機

- 斷點 900px：以下為手機版（側欄抽屜、目錄在課首、卡片兩欄）。
- 所有可點的東西最小高度 40px；測驗選項整列可點。
- 對完答案捲到測驗頂端時，手機要留出頂欄高度，不被遮住。

## 9. 驗收

1. `python3 -m unittest discover -s builder/tests` 全過，並新增：目錄產生（id 順序、有無課中練習）、圖示名稱檢查、`merge` 的 `_last` 與 `_wrong` 案例（兩邊都有、一邊移除、較舊的一邊不能復活）。
2. 建置後 `dist/` 裡搜不到任何 emoji，也搜不到舊色號 #F7F0E3、#B5730F、#5E7A9B。
3. 用瀏覽器實際跑一遍並截圖給 Tim：首頁、課文頁、對完答案、只重做錯的、錯題區清單與練習；各手機寬（390px）與電腦寬（1280px）兩種。
4. 兩台裝置登入同一帳號：一台答錯進錯題區，另一台登入後看得到；一台手動移除，另一台重新整理後消失。
5. 既有進度（只有 `{best,total,done}` 的舊格式）打開新版不壞、不丟。

## 10. 明確不做

- 一題一送出、遊戲化（等級、經驗值）。
- 深色模式。
- 跨模組的錯題總區。
- 課中練習收進錯題區。
- 修改任何課文或題目。
