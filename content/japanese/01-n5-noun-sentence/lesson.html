讀完這課你會

  • 用 AはBです 說「A 是 B」
  • 把名詞句改成否定、過去、問句
  • 用 も 說「也是」，用 の 接兩個名詞
  • 分清楚 こ・そ・あ・ど 指哪裡

開始之前，先看日文句子長什麼樣子

日文句子怎麼排、讀音怎麼看

日本語能力試驗（日檢）分 N5、N4、N3、N2、N1 五級，N5 最簡單、N1 最難。出處 官方從 2010 年改制起不公布各級的文法清單 出處，課裡標的級數是常見分級：依改制前的官方出題範圍與參考書的分法整理，各家大致一致、不完全相同。

動詞放在句子最後

  • 語順：中文是「主詞＋動詞＋受詞」（我 喝 咖啡），日文是「主詞＋受詞＋動詞」，動詞放在句尾。出處
  • 助詞：誰做、做什麼，靠接在名詞後面的助詞標出來。出處
  • 述語（句子裡說「怎麼了、是什麼」的那一塊）一定在最後，前面幾塊的順序比較自由。出處
  • 名詞當述語：「是學生」這種句子，名詞後面要接 です 或 だ。出處
  • 私わたしは　コーヒーを　飲のみます。我喝咖啡。（「喝」是 飲のみます，在句尾）
  • 私わたしは　学生がくせいです。我是學生。（中文的「是」在中間，日文的 です 在句尾）

第一句的 を 與 ます 在〈助詞（一）〉〈動詞的三類與ます形〉教。

讀音標在漢字上方

  • 漢字上方的小字是讀音：学生がくせい。
  • 同一個漢字在不同的詞裡讀法可能不同：「人」單獨是 人ひと，在「日本人」裡是 日本にほん人じん。

日文的句子，動詞放在哪裡？

  • 句子最前面
  • 主詞後面
  • 句子最後
  • 受詞前面

日文是「主詞＋受詞＋動詞」，動詞放在句尾；中文、英文是動詞夾在主詞與受詞中間。

最基本的句子：A 是 B

AはBです

「A 是 B」的日文是 AはBです。出處

名詞A＋は＋名詞B＋です

  • は：標出這句要談的主題，寫成 は、讀成 わ。出處 這課先學 AはBです 這一種；は 的其他用法在〈助詞（一）〉。
  • です：放在句尾，是 だ 的禮貌說法（敬體）。出處 跟朋友、家人說話用 だ 的說法（常體），在〈普通形與連接句子〉教；這幾課先學 です。
  • 可以不說的部分：從上下文看得出來的就不用說。自我介紹時，說 田中たなかです。 比說 私わたしは田中たなかです。 自然。出處
  • さん：稱呼別人時加在名字後面，男女都能用；自己的名字不加。出處
  • 私わたしは学生がくせいです。我是學生。
  • 田中たなかさんは会社員かいしゃいんです。田中先生是上班族。
  • 林りんさんは台湾人たいわんじんです。林小姐是台灣人。
  • 陳ちんさんは留学生りゅうがくせいです。陳先生是留學生。
  • 鈴木すずきさんは部長ぶちょうです。鈴木小姐是經理。
  • 今日きょうは休やすみです。今天是休假日。
  • はじめまして。王おうです。よろしくお願ねがいします。初次見面，我姓王，請多指教。

Ａ：お名前なまえは？Ｂ：私わたし（　）林りんです。

  • は
  • も
  • の
  • か

整句：Ａ：請問貴姓？Ｂ：我姓林。說「我是～」用 は 標出主題 私わたし。も 是「也是」，Ａ沒說自己姓林，說「我也姓林」不通。

  • です
  • は
  • の
  • も

整句：田中先生是上班族。名詞放在句尾當述語，後面要接 です。は、の、も 後面都還要再接東西，句子沒有結束。

自我介紹「我是田中」，下面哪一句對？

  • 田中たなかさんです。
  • 田中たなかです。
  • 田中たなかさんは。
  • 田中たなかだです。

さん 是稱呼別人用的，自己的名字不加：田中たなかです。 只說 田中たなかさんは。 句子沒說完；だ 和 です 不會疊在一起用。

第一天上班，跟上司說「我是新人」，用哪一句？

  • 新人しんじんです。
  • 新人しんじんだ。
  • 新人しんじんですか。
  • 新人しんじんだです。

整句：我是新人。對上司要用禮貌的說法 です。だ 是對朋友、家人的說法；加 か 變成問句；だ 和 です 不會疊在一起用。

A 不是 B

〜じゃありません／〜ではありません

否定句把 です 換成 じゃありません。出處

名詞A＋は＋名詞B＋じゃありません

  • じゃ 與 では：じゃ 是說話時用的；寫成文字時用 では，變成 ではありません。出處
  • じゃないです：也是 です 的否定，跟 じゃありません 意思一樣。出處

  • 鈴木すずきさんは学生がくせいじゃないです。会社員かいしゃいんです。鈴木小姐不是學生，是上班族。

私わたしは先生せんせい（　）。学生がくせいです。

  • です
  • じゃありません
  • じゃ
  • じゃないでした

整句：我不是老師，是學生。後一句說「是學生」，前一句要否定：じゃありません。用 です 會變成「我是老師，是學生」；只有 じゃ 句子沒說完；じゃないでした 不是標準說法。

じゃ 是說話時用的，寫成文字時用 では：ではありません。ではです 不是正確的形；じゃないでした 不是標準說法。

A 以前是 B

說過去的事，把 です 換成 でした。出處 過去的否定是 じゃありませんでした，也可以說 じゃなかったです。出處 寫成文字時一樣用 では：ではありませんでした。出處

把句子變成問句

〜か（疑問句）

句尾加 か 就是問句，語調往上揚。出處

名詞A＋は＋名詞B＋ですか

  • 回答：對的話說 はい、そうです。；不對的話說 いいえ、～じゃありません。 出處
  • 疑問詞（だれ、どこ 這類用來問的字）＋ですか：だれですか（是誰）、どこですか（在哪裡）這類問法，疑問詞後面接 ですか。出處

  • いいえ、先生せんせいじゃありません。学生がくせいです。不，他不是老師，是學生。

  • 会議かいぎは何なん曜日ようびですか。會議是星期幾？
  • 水曜日すいようびです。星期三。
  • すみません、トイレはどこですか。不好意思，廁所在哪裡？
  • 誕生日たんじょうびはいつですか。你生日是什麼時候？

Ａ：林りんさんは台湾人たいわんじんです（　）。Ｂ：はい、そうです。

〜も（也是）

も 是「也」：前面說過一件事，另一個人或另一樣東西也一樣時，把 は 換成 も。出處 簡單回一句「我也是」說 私わたしもです。 出處

名詞接名詞

名詞＋の＋名詞

の 把兩個名詞接起來，前面的名詞說明後面的名詞，像中文的「的」。出處

名詞＋の＋名詞

  • 誰的：私わたしの傘かさ（我的傘）。
  • 哪裡的：銀行ぎんこうの人ひと（銀行的人）。出處
  • 什麼樣的：日本語にほんごの先生せんせい（日文老師）、家族かぞくの写真しゃしん（全家福照片）。中文不說「的」的組合，日文也可能要 の。出處
  • 連好幾個：三個以上的名詞也能用 の 一路接下去：私わたしの会社かいしゃの部長ぶちょう（我們公司的經理）。出處
  • 前後是同一個：友達ともだちの陳ちんさん（朋友陳先生）——朋友就是陳先生。出處
  • 後面的名詞不說：私わたしの 單獨用就是「我的（東西）」：私わたしのです（是我的）。出處
  • 私わたしの傘かさです。這是我的傘。
  • 林りんさんは日本語にほんごの先生せんせいです。林小姐是日文老師。
  • 田中たなかさんは私わたしの友達ともだちです。田中先生是我的朋友。
  • 山田やまださんは銀行ぎんこうの人ひとです。山田小姐是銀行的人。
  • 友達ともだちの陳ちんさんです。這是我朋友陳先生。
  • 私わたしの会社かいしゃの部長ぶちょうです。這是我們公司的經理。
  • Ａ：だれの傘かさですか。Ｂ：鈴木すずきさんのです。Ａ：這是誰的傘？Ｂ：是鈴木小姐的。
  • 昨日きのうは母ははの誕生日たんじょうびでした。昨天是我媽媽的生日。

這個、那個、哪個

こ・そ・あ・ど

指東西、地方的字分成四組，開頭分別是 こ、そ、あ、ど。出處 用哪一組，看東西在誰旁邊：出處 出處

  • こ：在說話的人旁邊。
  • そ：在聽的人旁邊。
  • あ：離兩個人都遠。
  • ど：問「哪一個、哪裡」。出處

兩個人站在一起、在同一邊時分法不同：近的用 こ、稍遠的用 そ、很遠的用 あ。出處 這課先學上面的基本分法。

東西放在名詞前面地方
說話的人旁邊これこの＋名詞ここ
聽的人旁邊それその＋名詞そこ
兩個人都遠あれあの＋名詞あそこ
問哪一個どれどの＋名詞どこ
  • 名詞前面：要接名詞時用 この・その・あの，不用 これ・それ・あれ：✗ これ傘かさ → ✓ この傘かさ。出處
  • 換人說話，字就換組：對方問 それは何なんですか。（那是什麼？），東西在你手上，回答要用 これは～です。（這是～。）出處
  • 問地方：～はどこですか。 出處

  • Ａ：それは何なんですか。Ｂ：これは日本にほんのお菓子かしです。Ａ：那是什麼？Ｂ：這是日本的點心。
  • あれは駅えきです。那是車站。

「這裡不是車站。」是哪一句？

  • ここは駅えきじゃありませんでした。
  • ここも駅えきです。
  • ここは駅えきじゃありません。
  • ここは駅えきですか。

現在的否定是 じゃありません；じゃありませんでした 是過去。

重點整理

  • 日文動詞放在句尾；名詞當述語時接 です（敬體）或 だ（常體），這幾課用 です。
  • AはBです：A 是 B。は 標主題，讀 わ。看得出來的部分可以不說，自己的名字不加 さん。
  • 四個形：です、じゃありません、でした、じゃありませんでした。寫成文字時 じゃ 寫成 では。
  • 句尾加 か 是問句；回答 はい、そうです 或 いいえ、～じゃありません。疑問詞＋ですか：だれですか、どこですか、いつですか。
  • も 是「也」，放在 は 的位置；否定句的「也不是」一樣用 も。
  • の 接名詞：私わたしの傘かさ、日本語にほんごの先生せんせい、友達ともだちの陳ちんさん；私わたしのです 是「是我的」。
  • こ 說話的人旁邊、そ 聽的人旁邊、あ 兩人都遠、ど 問哪一個。接名詞用 この・その・あの・どの；地方用 ここ・そこ・あそこ・どこ。
