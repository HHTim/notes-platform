「如果～」「～的話」

四種條件的說法

這課學四種說「如果～就～」的方法：たら、と、ば、なら。它們都接在前半句（條件）的後面，後半句說條件成立時會怎樣、要做什麼。

前半句（條件）＋たら／と／ば／なら、後半句（結果）

接法這課先學的用法例子
たらた形＋ら如果～；～之後雨あめが降ふったら
と辭書形、ない形＋と一～就一定會～押おすと
ばば形如果～；條件成立就會～安やすければ
なら名詞、普通形＋なら接著對方剛說的話：～的話台南たいなんなら
  • 意思重疊：四個的意思有重疊，同一個位置有時不只一個能用。這課先學最容易分的幾條，後面「四個怎麼選」一節整理。
  • もし：「如果」，放在句子開頭，常跟 たら 一起用：もし時間じかんがあったら（如果有時間的話）。出處 出處
  • 〜になる：「變成～、到了～」，這課的例句常用：5時ごじになる（到了五點）、休やすみになる（變成放假）。

用途最廣的一個

〜たら 的接法

普通形的過去（た形、かった、だった）後面加 ら，就是 たら 的樣子。動詞、形容詞、名詞都一樣。出處 出處 出處

普通形過去＋ら（行いった→行いったら）

普通形過去たら否定的 たら
動詞（第一類）行いった行いったら行いかなかったら
動詞（第二類）食たべた食たべたら食たべなかったら
動詞（第三類）した、来きたしたら、来きたらしなかったら、来こなかったら
い形容詞高たかかった高たかかったら高たかくなかったら
な形容詞暇ひまだった暇ひまだったら暇ひまじゃなかったら
名詞雨あめだった雨あめだったら雨あめじゃなかったら
  • 先變 た形：た形的變法在〈ない形與た形〉，行いく→行いった 的例外一樣適用。
  • 来くる：た形是 来きた，所以是 来きたら（讀 きたら）。
  • 過去的樣子，不是過去的意思：たら 用的是過去的樣子，說的常常是還沒發生的事：明日あした、雨あめが降ふったら（明天如果下雨）。出處

行いく（去）的 たら 是？

  • 行いきたら
  • 行いったら
  • 行いいたら
  • 行いくたら

た形 行いった 加 ら。行いく 的 た形是例外，不是 行いいた。

食たべる（吃）的 たら 是？

  • 食たべったら
  • 食たべるたら
  • 食たべたら
  • 食たべりたら

第二類的 た形是去掉 る 加 た：食たべた，再加 ら。

来くる（來）的 たら，用平假名怎麼寫？

  • こたら
  • くたら
  • くるたら
  • きたら

来くる 的 た形讀 きた，所以 たら 讀 きたら。

高たかい（貴）的 たら 是？

  • 高たかかったら
  • 高たかいたら
  • 高たかくたら
  • 高たかいだったら

い形容詞的過去是 高たかかった，加 ら。い形容詞後面不加 だった。

暇ひま（有空，な形容詞）的 たら 是？

  • 暇ひまかったら
  • 暇ひまだったら
  • 暇ひまたら
  • 暇ひまなかったら

な形容詞的過去是 暇ひまだった，加 ら。かった 是い形容詞的變法。

明日あした、雨あめ（　）、家いえで映画えいがを見みます。（明天如果下雨，就在家看電影。）

  • だったら
  • たら
  • かったら
  • だら

整句：明天如果下雨，就在家看電影。雨あめ 是名詞，過去是 雨あめだった，たら 是 雨あめだったら。名詞後面不能直接接 たら。

わから（　）、聞きいてください。（如果不懂，請問我。）

  • ないたら
  • なくたら
  • なかったと
  • なかったら

整句：如果不懂，請問我。否定的過去是 わからなかった，加 ら：わからなかったら。ない 後面不能直接接 たら。

如果～；～之後

〜たら 的兩種意思

たら 說「前半句的事發生了以後，後半句的事會成立」，分兩種情況：出處 出處 出處

  • 如果～：不知道會不會發生，先假設：もし雨あめが降ふったら（如果下雨）。可以在開頭加 もし。
  • ～之後：一定會發生的事，說它發生以後要做什麼：授業じゅぎょうが終おわったら（下課以後）。這種不加 もし。
  • 後半句可以是請求、邀約、打算、想做：〜てください、〜ませんか、〜ましょう、〜ようと思おもいます、〜たいです 都可以接在 たら 後面。出處 出處
  • 疑問詞＋〜たらいいですか：問別人的建議（～比較好？）：どの店みせに行いったらいいですか（去哪家店比較好？）。出處 出處
  • 後半句是過去：意思變成「做了～，結果發現…」，後面是沒料到的事：店みせに行いったら、もう閉しまっていました（去了店裡，結果已經關門了）。出處
  • もし時間じかんがあったら、九份きゅうふんにも行いきたいです。如果有時間的話，也想去九份。
  • 仕事しごとが終おわったら、ジムに行いきます。下班以後去健身房。
  • 会議かいぎが終おわったら、資料しりょうを送おくってください。會議結束以後，請把資料寄給我。
  • 週末しゅうまつ、天気てんきがよかったら、山やまに登のぼりませんか。週末天氣好的話，要不要去爬山？
  • 熱ねつが下さがらなかったら、病院びょういんに行いってください。如果燒沒退，請去醫院。
  • 給料きゅうりょうが出でたら、新あたらしいスマホを買かおうと思おもいます。領到薪水以後，我打算買新的手機。
  • Ａ：夜市よいちで、何なにを食たべたらいいですか。Ｂ：臭豆腐しゅうどうふがおいしいですよ。Ａ：在夜市吃什麼比較好？Ｂ：臭豆腐很好吃喔。

会議かいぎが（　）、資料しりょうを送おくってください。（會議結束以後，請把資料寄給我。）

  • 終おわりたら
  • 終おわったら
  • 終おわるたら
  • 終おわったと

整句：會議結束以後，請把資料寄給我。終おわる 是第一類，た形 終おわった，加 ら。會議一定會結束，這是「～之後」的 たら。

仕事しごとが終おわったら、ジムに行いきます。 是什麼意思？

  • 如果工作沒做完，就去健身房
  • 工作的時候去健身房
  • 下班以後去健身房
  • 因為工作做完了，所以去了健身房

整句：下班以後去健身房。工作一定會結束，終おわったら 說的是「結束之後」。句尾 行いきます 是還沒去，不是「去了」。

下面哪一句的 たら 是「如果～（不知道會不會發生）」？

  • 授業じゅぎょうが終おわったら、図書館としょかんへ行いきます。
  • 8時はちじになったら、出でかけましょう。
  • 家いえに着ついたら、メールします。
  • もし宝たからくじが当あたったら、家いえを買かいたいです。

整句：如果中了樂透，想買房子。中不中樂透不知道，是假設，所以能加 もし。下課、到八點、到家都是一定會發生的事，那三句是「～之後」。

熱ねつが下さが（　）、病院びょういんに行いってください。（如果燒沒退，請去醫院。）

  • らなかったら
  • らないたら
  • りなかったら
  • らなくたら

整句：如果燒沒退，請去醫院。下さがる（下降）是第一類，ない形 下さがらない，過去 下さがらなかった，加 ら。

夜市よいちで、何なにを（　）いいですか。（在夜市吃什麼比較好？）

  • 食たべったら
  • 食たべるたら
  • 食たべたら
  • 食たべたと

整句：在夜市吃什麼比較好？問自己的事該怎麼選，用疑問詞＋〜たらいいですか。食たべる 是第二類，た形 食たべた，加 ら。

＿＿　＿＿　★　＿＿、電話でんわしてください。

  • 着ついたら
  • 台中たいちゅう
  • ホテルに
  • の

整句：到了台中的飯店以後，請打電話給我。の 接在 台中たいちゅう 和 ホテル 中間，着ついたら 放在最後接後半句。順序是 台中たいちゅう／の／ホテルに／着ついたら，★ 是 ホテルに。

一～就一定會～

〜と

前半句的事一成立，後半句的事一定跟著成立，用 と。出處 出處

動詞辭書形、ない形＋と；い形容詞＋と；名詞、な形容詞＋だと

  • 前面用現在的普通形：押おすと、押おさないと、安やすいと、タクシーだと；不用過去的樣子。出處
  • 常用在這幾種事：機器怎麼操作、路怎麼走、每次都這樣的事實或習慣、自然現象。出處
  • 後半句不能是這幾種說法：請求（〜てください）、打算（〜よう、〜ようと思おもいます）、想做（〜たいです）、邀約（〜ましょう、〜ませんか）、禁止（〜てはいけません）都不能接在 と 後面；這些可以改用 たら。出處
  • 只發生一次的事：未來只發生一次的事，用 たら，不用 と。出處
  • 不同的 と：〈助詞（一）〉的 と（和、一起）接在名詞後面；〈普通形與連接句子〉的 〜と思おもいます 後面接 思おもいます。這課的 と 前面是一句話，後面再接另一句話。
  • この赤あかいボタンを押おすと、お湯ゆが出でます。一按這個紅色按鈕，就會出熱水。
  • 二ふたつ目めの信号しんごうを右みぎに曲まがると、駅えきが見みえます。在第二個紅綠燈右轉，就看得到車站。
  • 台風たいふうが来くると、学校がっこうが休やすみになります。颱風一來，學校就會放假。
  • 父ちちは家いえに帰かえると、すぐテレビをつけます。我爸爸一回到家，就馬上開電視。
  • 早はやく出でないと、電車でんしゃに間まに合あいません。不早點出門的話，會趕不上電車。
  • タクシーだと、空港くうこうまで40分よんじゅっぷんぐらいです。搭計程車的話，到機場大約四十分鐘。

この赤あかいボタンを（　）、お湯ゆが出でます。（一按這個紅色按鈕，就會出熱水。）

  • 押おしたと
  • 押おすと
  • 押おすたら
  • 押おしと

整句：一按這個紅色按鈕，就會出熱水。機器的操作，用辭書形＋と：押おすと。と 前面不放過去的 押おした，也不放ます形的 押おし。

二ふたつ目めの信号しんごうを右みぎに（　）、駅えきが見みえます。（在第二個紅綠燈右轉，就看得到車站。）

  • 曲まがると
  • 曲まがったと
  • 曲まがりと
  • 曲まがるたら

整句：在第二個紅綠燈右轉，就看得到車站。說路怎麼走，用辭書形＋と：曲まがると。

台風たいふうが（　）、学校がっこうが休やすみになります。（颱風一來，學校就會放假。）

  • 来きたと
  • 来くると
  • 来きと
  • 来くるたと

整句：颱風一來，學校就會放假。每次都這樣的事，用辭書形 来くる＋と。

早はやく（　）、電車でんしゃに間まに合あいません。（不早點出門的話，會趕不上電車。）

  • 出でないと
  • 出でなくと
  • 出でなかったと
  • 出でないたと

整句：不早點出門的話，會趕不上電車。否定用 ない形＋と：出でないと。間まに合あう 是「趕得上」。

タクシー（　）、空港くうこうまで40分よんじゅっぷんぐらいです。（搭計程車的話，到機場大約四十分鐘。）

  • なと
  • のと
  • と
  • だと

整句：搭計程車的話，到機場大約四十分鐘。名詞接條件的 と 要加 だ：タクシーだと。只放 と 會變成「和計程車」。

下面哪一句不對？

  • このボタンを押おすと、ドアが開あきます。
  • いつも家いえに帰かえると、すぐシャワーを浴あびます。
  • 日本にほんへ行いくと、富士山ふじさんに登のぼりたいです。
  • 右みぎに曲まがると、コンビニがあります。

整句：（想說的是）去日本的話，想爬富士山。〜たいです 是想做的事，不能接在 と 後面，要說 日本にほんへ行いったら。另外三句是機器、習慣、路線，用 と 都對。

  • 卒業そつぎょうしたと
  • 卒業そつぎょうしたら
  • 卒業そつぎょうしったら

整句：大學畢業以後，想在日本工作。後半句是 〜たいです，と 不能用；用 する 的 た形 した＋ら：卒業そつぎょうしたら。

動詞、形容詞的另一個樣子

ば形怎麼變

語尾變成 ば 的樣子叫 ば形，用來說條件。出處 出處 跟其他變化一樣，要先知道是哪一類動詞：

  • 第一類：辭書形最後一個音從 う段 換成 え段，加 ば：書かく→書かけば、買かう→買かえば。出處
  • 第二類：去掉 る，加 れば：食たべる→食たべれば、見みる→見みれば。出處
  • 第三類：する→すれば，来くる→来くれば（讀 くれば）。出處
  • い形容詞：去掉 い，加 ければ：安やすい→安やすければ。いい 從 よい 變：よければ。出處 出處
  • 否定：ない 照い形容詞變成 なければ：行いかない→行いかなければ。〈ない形與た形〉的 〜なければなりません 就是這個樣子，字面是「不做的話不行」。出處
  • な形容詞、名詞：用 なら：静しずかなら、雨あめなら。なら 是 だ 的這個樣子，也可以寫成 ならば。出處 出處

如果～就～

〜ば 的用法

  • 假設：還沒成立的事，假設它成立：時間じかんがあれば、行いきます（有時間的話就去）。出處
  • 條件成立就會這樣：在這個條件下，每次都會發生的事：このアプリを使つかえば、バスの時間じかんがすぐわかります（用這個 App，馬上就知道公車的時間）。這種意思跟 と 很像。出處
  • 疑問詞＋〜ばいいですか：問做法、規矩（要怎麼做才好？）：どうすればいいですか（該怎麼辦才好？）。問規矩、大家都這樣做的事時常用 〜ばいいですか；問自己的事要怎麼選（去哪裡玩、住哪裡）時常用 〜たらいいですか。兩個都對。出處
  • 時間じかんがあれば、一緒いっしょに夜市よいちへ行いきましょう。有時間的話，一起去夜市吧。
  • もう少すこし安やすければ、買かいます。再便宜一點的話我就買。
  • 明日あした、天気てんきがよければ、海うみに行いきます。明天天氣好的話，就去海邊。
  • この薬くすりを飲のめば、すぐ治なおりますよ。吃了這個藥，很快就會好喔。
  • 急いそがなければ、終電しゅうでんに間まに合あいません。不快一點的話，會趕不上末班電車。

接著對方剛說的話

〜なら

對方說了一件事，接著那件事給建議、說意見，用 なら：「～的話」。なら 前面放對方話裡的關鍵詞。出處 出處

名詞、な形容詞＋なら；動詞、い形容詞的普通形＋なら

  • 名詞、な形容詞直接接：台南たいなんなら、暇ひまなら；不加 だ、な。出處
  • 動詞、い形容詞接普通形：行いくなら、痛いたいなら。出處 出處
  • 也能說假設：なら 也能說「如果是～的話」，不一定接對方的話：現金げんきんなら、この店みせで払はらえます（現金的話，可以在這家店付）。出處

「今晚有空的話，要不要去夜市？」是哪一句？

  • 今晩こんばん暇ひまだと、夜市よいちに行いきませんか。
  • 今晩こんばん暇ひまかったら、夜市よいちに行いきませんか。
  • 今晩こんばん暇ひまたら、夜市よいちに行いきませんか。
  • 今晩こんばん暇ひまだったら、夜市よいちに行いきませんか。

整句：今晚有空的話，要不要去夜市？後半句是邀約 〜ませんか，と 不能用；暇ひま 是な形容詞，たら 是 暇ひまだったら。

重點整理

  • たら：普通形過去＋ら（行いったら、来きたら、高たかかったら、暇ひまだったら、雨あめだったら）。
  • たら 說「如果～」（可加 もし）和「～之後」；後面可以接請求、邀約、打算、想做。
  • と：辭書形、ない形＋と，名詞＋だと；說機器、路線、自然、習慣這種每次都會這樣的事。
  • と 後面不接請求、打算、想做、邀約、禁止。
  • ば形：第一類 う段→え段＋ば（書かけば），第二類 る→れば，すれば、来くれば，い形容詞 い→ければ（よければ），否定 なければ，な形容詞與名詞用 なら。
  • 問做法、規矩：疑問詞＋〜ばいいですか；問建議也可以用 〜たらいいですか。
  • なら：接著對方剛說的話（台南たいなんなら）；名詞、な形容詞直接接，動詞、い形容詞接普通形。
