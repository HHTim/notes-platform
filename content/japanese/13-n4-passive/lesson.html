「被～」的動詞樣子

被動形是什麼；第一類怎麼變

動詞變成「被～」意思的樣子叫被動形（日文叫「受身うけみ」）：呼よぶ（叫）→呼よばれる（被叫）。出處 出處

第一類的被動形：辭書形最後一個音從 う段 換成 あ段，再加 れる。出處 出處

第一類：〜う段 → 〜あ段＋れる（書かく→書かかれる）

書かく書かかれる被寫
押おす押おされる被推、被按
待まつ待またれる被等

  • う 變成 わ：辭書形結尾是 う 的，換成 わ 不是 あ：言いう→言いわれる、使つかう→使つかわれる。出處
  • 跟ない形對照：ない 前面的音，就是 れる 前面的音：呼よばない→呼よばれる、言いわない→言いわれる。出處 出處
  • 跟可能形不一樣：第一類的可能形是え段＋る，被動形是あ段＋れる：書かける（能寫）、書かかれる（被寫）。可能形在〈可能形〉。
  • る 結尾的第一類：る→ら＋れる：取とる→取とられる、しかる→しかられる。出處 出處

下面哪一組「辭書形 → 被動形」是錯的？

  • 見みる → 見みられる

書かく 是第一類，被動形是 書かかれる。見みる 是第二類加 られる；取とる 是第一類，る→ら＋れる；待まつ→待またれる；這三組都對。

人被別人做了某件事

被罵、被稱讚：〜に〜（ら）れる

站在「受到動作的人」的角度說話，就用被動：受到動作的人當主詞，做動作的人用 に 標。出處 出處 出處

受到動作的人＋は　做動作的人＋に　被動形

課長かちょうが私わたしをほめました → 私わたしは課長かちょうにほめられました

  • 主詞換人：原來用 を 標的人（私わたしを）變成主詞，原來的主詞（課長かちょうが）改用 に。出處
  • 私わたしは 常常不說：受到動作的是說話的人自己，或聽的人知道是誰時，主詞常常省略。出處
  • 做動作的人也可以不說：佐藤さとうさんの結婚式けっこんしきに招待しょうたいされました。（我受邀參加佐藤先生的婚禮。）這裡的 に 是「到婚禮」，不是做動作的人。

注意ちゅういされる 這種從別人那裡收到話的動詞，做動作的人也可以用 から。出處 這課的練習一律用 に。

  • 私わたしは課長かちょうにほめられました。我被課長稱讚了。
  • 林りんさんは社長しゃちょうに呼よばれました。林先生被社長叫去了。
  • 弟おとうとは宿題しゅくだいをしなかったから、父ちちにしかられました。弟弟因為沒寫功課，被爸爸罵了。
  • 佐藤さとうさんの結婚式けっこんしきに招待しょうたいされました。我受邀參加佐藤先生的婚禮。
  • 電車でんしゃの中なかで、知しらない人ひとに話はなしかけられました。在電車裡，被不認識的人搭話了。
  • 図書館としょかんで大おおきい声こえで話はなしたから、注意ちゅういされました。因為在圖書館大聲說話，被提醒了。

  • で

  • へ

整句：我被課長稱讚了。被動句裡做動作的人用 に 標：課長かちょうに。

  • 招待しょうたいできました

  • 注意ちゅういできました

東西、身體受到影響

東西被偷、被吃掉：〜に〜を〜（ら）れる

自己的東西或身體被別人做了什麼，日文用「人」當主詞，東西用 を 標，動詞用被動形。出處 出處

（私わたしは）　做動作的人＋に　東西＋を　被動形

  • 主詞是受到影響的人：被吃掉的是蛋糕，覺得困擾的是說話的人，所以說話的人當主詞。出處
  • 中文常說「我的～被～」：日文這個說法的形狀比較像「我被～了～」：私わたしは妹いもうとにケーキを食たべられました。（我的蛋糕被妹妹吃掉了。）
  • 身體也一樣：腳、手被踩、被叮，也用這個形狀。出處
  • 夜市よいちで、スマホを盗ぬすまれました。在夜市手機被偷了。
  • 冷蔵庫れいぞうこのケーキを妹いもうとに食たべられました。冰箱裡的蛋糕被妹妹吃掉了。
  • 弟おとうとにパソコンを壊こわされました。電腦被弟弟弄壞了。
  • 蚊かに足あしを刺さされました。腳被蚊子叮了。
  • 友ともだちに私わたしの日記にっきを読よまれました。我的日記被朋友看了。

  • で
  • へ
  • を

  • で
  • へ

害自己困擾的事

被雨淋：受害的被動

別人做了某件事、發生了某件事，害自己困擾，也可以用被動說，就算那件事沒有直接做在自己身上。出處 出處 出處

（私わたしは）　做那件事的人或東西＋に　被動形

  • 不接 を 的動詞也能用：降ふる（下雨）、泣なく（哭）、来くる 這種前面沒有受詞的動詞，也能變成這種被動：雨あめに降ふられる。出處
  • 中文常常不說「被」：隣となりの人ひとにピアノを弾ひかれました 中文是「隔壁的人彈鋼琴（吵到我）」。日文用被動，就帶出「我很困擾」的感覺。出處
  • 只說事實就不用被動：雨あめが降ふりました（下雨了）只說天氣；雨あめに降ふられました（被雨淋了）說的是自己碰上雨、受到影響。
  • 駅えきまで歩あるいているとき、雨あめに降ふられました。走去車站的路上，被雨淋了。
  • 夜中よなかに隣となりの人ひとにピアノを弾ひかれたから、よく眠ねむれませんでした。半夜隔壁的人彈鋼琴，害我沒睡好。
  • 飛行機ひこうきで、隣となりの席せきの赤あかちゃんにずっと泣なかれました。在飛機上，隔壁座位的嬰兒一直哭（我很困擾）。
  • 試験しけんの前まえの日ひに友ともだちに来こられたから、勉強べんきょうできませんでした。考試前一天朋友跑來，害我沒辦法唸書。

駅えきまで歩あるいているとき、雨あめ（　）降ふられました。（走去車站的路上，被雨淋了。）

  • が
  • に
  • で
  • を

整句：走去車站的路上，被雨淋了。被動句裡，害自己困擾的那個（這裡是雨）用 に：雨あめに降ふられる。只說「下雨」才是 雨あめが降ふる，動詞不用被動形。

夜中よなかに隣となりの人ひと（　）ピアノを弾ひかれました。（半夜隔壁的人彈鋼琴，吵到我。）

  • で
  • へ
  • に
  • を

整句：半夜隔壁的人彈鋼琴，吵到我。彈鋼琴的人用 に：隣となりの人ひとに。鋼琴不是說話的人的東西，但說話的人覺得困擾，所以用被動。

  • 雨あめが降ふっています。
  • 雨あめが降ふったら、行いきません。
  • 雨あめに降ふられました。

整句：被雨淋了。雨あめに降ふられました 用被動，說的是自己受到影響。雨あめが降ふりました（下雨了）、降ふっています（正在下雨）只說天氣；降ふったら 是「如果下雨就不去」。

不說是誰做的

東西當主詞：〜は〜（ら）れました

建築、作品、活動這些東西當主詞，說它被建造、被做出來、被舉辦，也用被動形。這時候做的人通常不說。出處 出處 出處

東西＋は／が　被動形（建たてられました、開ひらかれます）

  • 用在說明、新聞、公告：這種說法多出現在說明、新聞、正式的通知。出處 出處 平常聊天說活動，常說 夜市よいちでイベントがあります（夜市有活動）就好。出處
  • 要說是誰做的：用 によって（由～）：この駅えきは、日本にほんの会社かいしゃによって設計せっけいされました。（這個車站是由日本公司設計的。）出處
  • 〜ています：話はなされています、作つくられています 說的是現在一直是這樣的狀態（〈て形〉的 〜ています）。
  • 龍山寺りゅうざんじは1738年せんななひゃくさんじゅうはちねんに建たてられました。龍山寺是 1738 年創建的。
  • 来月らいげつ、台北たいぺいで日本語にほんごのスピーチ大会たいかいが開ひらかれます。下個月在台北舉辦日語演講比賽。
  • 台湾たいわんでは、中国語ちゅうごくごや台湾語たいわんごが話はなされています。在台灣，大家說中文、台語等等。
  • このお茶ちゃは、台湾たいわんの山やまで作つくられています。這種茶是在台灣的山上製作的。
  • この駅えきは、日本にほんの会社かいしゃによって設計せっけいされました。這個車站是由日本公司設計的。

  • 這種茶是在台灣的山上製作的

整句：這種茶是在台灣的山上製作的。茶是被做出來的東西，作つくられています 是 作つくる 的被動形加 ています，說平常一直在那裡製作。作つくる 是第一類，可能形是 作つくれる，不是這個樣子。

被動還是可能？

第二類和 来くる 的被動形跟可能形同一個樣子，要從整句的意思判斷。出處 出處 第一類兩個樣子不一樣（書かける、書かかれる），不會混。

  • 私わたしは辛からい料理りょうりが食たべられません。我不能吃辣的菜。（可能）
  • 妹いもうとにプリンを食たべられました。布丁被妹妹吃掉了。（被動）
  • 私わたしは土曜日どようびも会社かいしゃに来こられます。我星期六也能來公司。（可能）
  • 母ははに古ふるい写真しゃしんを見みられました。舊照片被媽媽看到了。（被動）

說話時常聽到的 見みれる、食たべれる（拿掉 ら 的說法，在〈可能形〉）只當「能～」用，不當被動。出處

下面哪一句的動詞是「被～」的意思？

  • 私わたしは朝あさ早はやく起おきられません。
  • この店みせでは、台湾料理たいわんりょうりが食たべられます。

  • 私わたしは明日あしたも来こられます。

整句：我被部長罵了。しかる 是第一類，しかられる 在這句是被動形，不是可能形（可能形是 しかれる）。其他三句：我沒辦法早起、這家店可以吃到台灣菜、我明天也能來，都是可能形。

このマンガは、世界中せかいじゅうで（　）。（這部漫畫在全世界都有人讀。）

  • 読よみられています
  • 読よまれています
  • 読よめれています
  • 読よむれています

整句：這部漫畫在全世界都有人讀。漫畫當主詞，用 読よむ 的被動形 読よまれる，加 ています 說現在一直是這樣。

重點整理

  • 第一類：う段→あ段＋れる（書かかれる、呼よばれる）；う 結尾變 わ（言いわれる）。
  • 第二類：去 る 加 られる（ほめられる）。第三類：する→される，来くる→来こられる。
  • 被動形照第二類變：しかられます、しかられない、しかられた。
  • 被罵、被稱讚：受到動作的人＋は，做動作的人＋に（課長かちょうにほめられました）。
  • 東西、身體：人當主詞，東西用 を（妹いもうとにケーキを食たべられました）。
  • 害自己困擾：雨あめに降ふられました、隣となりの人ひとにピアノを弾ひかれました；不接 を 的動詞也能用。
  • 東西當主詞：建たてられました、開ひらかれます，多用在說明、新聞；說是誰做的用 によって。
  • 第二類和 来くる 的被動形跟可能形同一個樣子，看整句意思分。
