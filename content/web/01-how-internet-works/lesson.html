先建立全貌

網際網路不只是一堆電纜

網際網路（Internet）是由許多彼此連接的網路組成的「網路之網」——除了纜線，還有路由器、交換器、伺服器，以及大家共同遵守的通訊協定出處。家用網路、公司網路、電信商骨幹與資料中心，會透過光纖、海底電纜、銅線、行動網路、微波或衛星等媒介互相連接。

可以把網際網路想成全球道路系統：傳輸媒介是道路，路由器像交流道，IP 位址像門牌，而通訊協定則是共同遵守的交通規則。

全球資訊網（World Wide Web，WWW）只是運行在網際網路上的其中一種服務。它主要使用 HTTP 或 HTTPS 傳送網頁資源；電子郵件、網路電話與線上遊戲也會使用網際網路，卻不等於 WWW。

誰提供內容

用戶端、瀏覽器與伺服器

瀏覽器是用戶端（Client）：它替使用者提出請求、接收資料，再把內容呈現出來。伺服器（Server）則是提供資源或功能的電腦或程式，例如回傳 HTML、圖片、影片或 API 資料。

伺服器可以是實體主機、虛擬機、容器，或雲端服務上執行的伺服器軟體；除了存放檔案，也會執行運算、驗證與應用程式邏輯出處。

HTML 描述頁面的內容與結構，CSS 負責外觀，JavaScript 負責互動。瀏覽器取得這些資源後，才會解析並呈現網頁。

接上全球網路

ISP 與路由器扮演什麼角色？

網際網路服務供應商（Internet Service Provider，ISP）提供使用者連上網際網路的服務，連線方式可能是光纖、纜線、DSL 或行動網路等技術出處。

資料離開裝置後，通常會經過家用路由器、ISP 網路及多個中繼路由器。每台路由器會查看目的 IP，依路由表選擇下一站。它很像轉運站，但不保證每個封包都走完全相同的路。

網路門牌

IP 位址負責定位設備

IP 位址是網際網路層用來識別來源與目的地的位址。IPv4 是 32 位元，例如 192.0.2.44；IPv6 是 128 位元，例如 2001:db8::44，可提供大得多的位址空間。

IP 不一定永久對應某一台實體主機。它可能由 ISP 動態分配，也可能指向負載平衡器、內容傳遞網路（CDN）或一組伺服器。

給人看的名稱

網域名稱、URL 與 DNS 不一樣

網域名稱（Domain Name）是階層式名稱，例如 example.com；URL（統一資源定位符）則描述某項資源的完整位置。

https://www.example.com:443/products?id=7

部分範例作用
通訊協定https指定如何通訊
主機名稱www.example.com指出要連線的主機名稱
連接埠443指出主機上的服務入口
路徑/products指出資源位置
查詢字串id=7附帶請求參數

www 是 example.com 下的一個標籤，常被用作子網域或主機名稱，但並非所有網站都必須使用。URL 與網域是不同層次的概念：同一個網域下可以有無數個 URL，URL 指向的也不只網頁，還可以是圖片、樣式檔、API 或動態內容出處。

網路電話簿

DNS 如何把名稱解析成位址？

網域名稱系統（Domain Name System，DNS）負責查詢名稱相關紀錄。最常見的結果是 IPv4 的 A 紀錄或 IPv6 的 AAAA 紀錄，但 DNS 也能保存郵件、別名與名稱伺服器等資料。

裝置通常先查看瀏覽器或作業系統快取，再詢問遞迴解析器（Recursive Resolver）。若沒有快取，解析器會沿著 DNS 階層尋找：

  1. 根名稱伺服器指出相關頂級網域伺服器。
  2. 頂級網域（TLD）伺服器指出該網域的權威名稱伺服器。
  3. 權威名稱伺服器回答正式 DNS 紀錄。
  4. 遞迴解析器將結果傳回裝置，並依 TTL 暫存。

根與 TLD 伺服器通常提供下一站的指引，而不是一路把查詢「往上轉發」。快取可減少延遲與重複查詢。

把大資料拆小

封包、TCP/IP 與四層分工

網路資料會被封裝成適合傳輸的單位。不同層對資料單位有更精確的名稱；入門時可以先統稱為封包，再理解每一層加入的標頭。

TCP/IP 層負責事項常見例子
應用層定義應用如何交換內容HTTP、DNS、SMTP
傳輸層端點通訊、連接埠與可靠性TCP、UDP
網際網路層跨網路定址與路由IP
網路存取層在本地媒介上傳送資料Ethernet、Wi-Fi

TCP 像有簽收與補寄機制的配送：建立連線後，透過序號、確認與重傳等機制提供有序、可靠的位元組串流。TCP 把資料切成一段段的 segment（區段）傳送，每段帶有序號與檢查碼；錯誤偵測與重傳是 TCP 在傳輸層做的事，不是網路存取層出處。UDP 像快速投遞：開銷較少，但本身不保證抵達、順序或不重複；應用程式可依需求自行補上機制。

可靠就一定比較好嗎？不一定。檔案下載重視完整性，常適合 TCP；即時語音更怕等待，可能選 UDP 或以 UDP 為基礎、另行提供可靠性的現代協定。

這課的關鍵

  • Internet 是底層互聯網路；WWW 是其上的 Web 資訊系統。
  • DNS 把好記的名稱解析成連線所需的紀錄，URL 則描述資源位置。
  • 路由器依目的 IP 轉送封包；TCP 與 UDP 提供不同的傳輸取捨。
