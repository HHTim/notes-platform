語法骨架

類別、main 方法與敘述

Java 的程式碼一律寫在類別裡，敘述用分號結尾，大括號界定程式區塊（block）。最常見的進入點長這樣：

public class Main {
    public static void main(String[] args) {
        System.out.println("開始執行");
    }
}

Java 區分大小寫，所以 Main、main、MAIN 是三個不同名稱。命名慣例照 Oracle 的寫法是「mixed case」——類別名稱每個字的字首都大寫（例如 HelloWorld），方法與變數第一個字小寫、後面每個字的字首大寫（例如 myName），常數全大寫加底線。中文圈常把前者叫大駝峰、後者叫小駝峰。

替資料貼標籤

變數、常數與有效範圍

變數像有名字的置物盒，但盒子只收得下宣告時講好的型別。Java 是強型別語言，宣告一定要講型別。

int age = 20;
double height = 1.72;
String userName = "小華";
final double TAX_RATE = 0.05;

= 是指定運算子（assignment operator）：先算右邊，再把結果放進左邊。跟數學的等號不一樣，所以 x = x + 1 是合法的。加上 final 的變數一旦給了值就不能再改，等於常數。

種類宣告在哪有沒有預設值
區域變數方法或程式區塊內沒有，用之前一定要先給值
實體變數（欄位）類別內、方法外，沒有 static有，數字給 0、布林給 false、參考型別給 null
類別變數類別內、方法外，有 static有，規則同上

var 是 Java 10 才加進來的寫法，讓編譯器從初始值自己推出型別出處。它有兩個限制：只能用在區域變數（不能當欄位或方法參數），而且宣告當下一定要給初始值，編譯器才推得出來。

var total = 0;              // 推成 int
var names = new ArrayList<String>();  // 推成 ArrayList<String>
// var x;                   // 不行，沒有初始值

二進位表示法與數字中間的底線分隔，都是 Java 7 開始才有的寫法。

算式裡的規則

算術、型別提升與轉型

+　-　*　/　%

% 取餘數。兩個整數相除得到整數，小數直接砍掉；只要有一邊是浮點數，就變成浮點數除法。

System.out.println(5 / 10);    // 0   ← 不是 0.5
System.out.println(5.0 / 10);  // 0.5
System.out.println(7 % 3);     // 1

+ 碰到字串會變成串接，而且是由左往右算，所以 15 + 15 + "15" 得到字串 "3015"。

小範圍的數值會自動提升成大範圍；反過來要自己明寫轉型，而且可能掉資料。完整的提升順序是 byte、short、char → int → long → float → double；char 雖然裝的是字元，在運算時一樣會被提升成 int出處。

double total = 10 + 2.5;       // 12.5
int roundedDown = (int) 12.9;  // 12，小數砍掉不是四捨五入
int count = 3;
count += 2;                    // 等同 count = count + 2

byte s1 = 10;
byte s2 = 100;
// byte sum = s1 + s2;         // 編譯錯誤
int sum = s1 + s2;             // 可以

兩個 byte 相加會先各自提升成 int 再算，結果也是 int，所以不能直接塞回 byte。這叫二元數值提升，是語言規格直接訂死的規則。至於 byte s1 = 10; 為什麼可以，是因為 10 是編譯期就知道的常數，編譯器允許這種窄化。

先用舊值還是新值

遞增、比較與邏輯運算

value++ 是先取目前的值、再加一；++value 是先加一、再取值。單獨放一行時兩者結果一樣，混在複雜算式裡就很容易看錯。

int num1 = 3;
System.out.println(num1++);  // 印 3，之後 num1 變 4
System.out.println(++num1);  // num1 先變 5，印 5

照規格，「一元」「二元」講的是這個運算子吃幾個運算元，不是某一類運算子的專屬別名。算術運算子多半是二元的，但 &&、== 也是二元；++、-- 是一元的，但 !、~、正負號和轉型也都是一元出處。

&& 與 || 會短路：結果已經確定時，右邊那串就不算了。比較字串內容要用 equals；== 用在參考型別上比的是「是不是同一個物件」——這點第 3 課會細講。

讓程式做選擇

if、switch 與三元運算子

int score = 82;

if (score >= 90) {
    System.out.println("優良");
} else if (score >= 60) {
    System.out.println("通過");
} else {
    System.out.println("再試一次");
}

寫成 if (bmi < 18.5) …… else if (bmi >18.5 && bmi < 24) …… 這種形狀要小心：18.5、24、30 這三個邊界值剛好掉進所有分支之外、什麼都不印。連續區間的判斷建議統一用 >= 接起來，或直接靠 else 收尾。

switch 適合拿單一個值去挑分支。傳統寫法如果漏了 break，會繼續往下執行後面的 case，這叫貫穿（fall-through）。

String level = "B";

switch (level) {
    case "A":
        System.out.println("優良");
        break;
    case "B":
        System.out.println("通過");
        break;
    default:
        System.out.println("未分類");
}

規格訂得很清楚：switch 的判斷值可以是 char、byte、short、int（以及對應的包裝類別）、String（Java 7 起）與列舉 enum（Java 5 起）；long、float、double、boolean 都不行。case 標籤只能放常數，&& 不行、|| 也不行出處。

新版有比較好寫的形式：Java 14 起 switch 可以當運算式直接回傳值，箭頭寫法也不會貫穿，不必再補 break。

// Java 14 起的寫法
String result = switch (level) {
    case "A" -> "優良";
    case "B" -> "通過";
    default  -> "未分類";
};

Java 21 又放寬一次：case 標籤可以直接寫型別樣式，所以判斷值不再限於上面那幾種型別，任何物件都可以拿來比對，還能用 when 加條件出處。這就是第 1 課版本分水嶺裡提到的「switch 的型樣比對」。

// Java 21 起
String describe(Object o) {
    return switch (o) {
        case Integer i when i > 100 -> "很大的整數 " + i;
        case Integer i                -> "整數 " + i;
        case String str               -> "字串 " + str;
        default                       -> "其他";
    };
}

「switch 比 if-else 快」這句要看情況：分支多的時候編譯器確實可能產生查表式的跳躍指令，但只有三五個分支時差異小到量不出來——挑哪一種請以讀起來清不清楚為準。

重複工作

for、while、do-while

迴圈有三個要素：初值設定、條件判斷、計次。for 適合已知跑幾次，while 適合「跑到某個條件為止」，do-while 會先做一次再檢查條件。

for (int i = 0; i < 3; i++) {
    System.out.println(i);
}

int count = 0;
while (count < 3) {
    count++;
}

do {
    System.out.println("至少執行一次");
} while (false);

for 與 while 是前測式（可能一次都不跑），do-while 是後測式（至少跑一次）。break 跳出整個迴圈，continue 只跳過這一輪剩下的敘述、進下一輪。兩者都可以搭配標籤指定要跳出哪一層：

int i = 1;
outer:
while (i <= 3) {
    int j = 1;
    while (j <= 5) {
        if (j == 4) {
            break outer;   // 直接跳出外層那個迴圈
        }
        j++;
    }
    i++;
}

不帶標籤的 break 可以用在迴圈與傳統 switch 裡，continue 只能用在迴圈裡。標籤則不限迴圈——任何敘述（包括一個大括號程式區塊）都能加標籤，break 標籤 也跳得出來；只有 continue 標籤 規定那個標籤一定要標在迴圈上。

把工作命名

方法、參數、回傳值與多載

public static int add(int left, int right) {
    return left + right;
}

int result = add(2, 3);

方法宣告由修飾子、回傳型別、方法名稱與參數列組成。宣告裡的 left、right 叫參數（parameter）；呼叫時真的送進去的 2、3 叫引數（argument）。void 表示不回傳東西。

方法多載（overloading）＝同一個類別裡好幾個方法共用名稱，但參數的數量、型別或順序不同。Java 靠「方法名稱＋參數列」這個組合（方法簽章）決定要呼叫哪一個，不能只靠回傳型別區分。

static double area(double radius) {            // 圓
    return radius * radius * Math.PI;
}

static double area(double height, double width) {  // 長方形
    return height * width;
}

// static int area(double radius) { }          // 不行，只有回傳型別不同

方法自己呼叫自己

遞迴與呼叫堆疊

遞迴（recursion）就是方法呼叫它自己，把大問題一層層縮小。每一次呼叫都會在呼叫堆疊（call stack，記錄「現在走到哪、還有誰在等結果」的那疊資料）上多壓一層，結束時再從最上面一層層彈回來——後進先出。

static int sumTo(int n) {
    if (n == 0) {
        return 0;      // 終止條件
    }
    return n + sumTo(n - 1);
}

遞迴一定要有終止條件，而且每次都要往終止條件靠近。否則堆疊一直長高，最後就是 StackOverflowError。

重點整理

  • = 是指定、== 是比較；比字串內容要用 equals。
  • 兩個整數相除會砍掉小數；+ 碰到字串就變串接。
  • 運算時 byte、short、char 都會先提升成 int，所以兩個 byte 相加塞不回 byte。
  • switch 的判斷值不能是 long、浮點數或 boolean；Java 14 起可以用箭頭寫法當運算式。
  • for、while 可能一次都不跑；do-while 至少跑一次。
  • 多載靠參數列區分，改回傳型別沒有用；遞迴一定要有終止條件。
