真的還是假的，現在還是過去

條件句四型總覽

這課講的是用 if 講條件的句子。suggest、insist、It is important that 後面接原形動詞的那種用法，英文文法也歸在假設語氣（subjunctive）底下，在〈名詞子句〉那課。

條件句由兩段組成：講條件的 if 子句（條件子句），和講結果的主要子句。劍橋：If a lot of people come, we'll have to get extra chairs.，前半是條件子句、後半是主要子句（Conditional sentences consist of a conditional clause and a main clause）。出處

這課的重點是：if 子句用什麼時態，透露說話的人覺得這件事有多可能。劍橋：「條件子句的動詞反映說話者的看法：想像的情況是有可能，還是不可能」（The verb in the conditional clause reflects the speaker's point of view on whether the imagined situation is likely or impossible）。出處 劍橋同一頁的三個例子剛好排成一排：

  • If you win the next match, will you be in the semi-final?：現在式＋will，說話的人覺得「贏」有可能。
  • If I won a million pounds, I would give this job up tomorrow!：過去式＋would，覺得「中一百萬」不太可能。
  • If we had won the competition, we would have had a free trip to Moscow.：過去完成式＋would have，條件不可能——事情已經沒發生了（the event did not happen）。出處
類型講什麼if 子句主要子句例句
零條件一般事實、規則（每次都這樣）現在式現在式If a payment is late, the system sends a reminder.
第一類未來真的有可能發生現在式will／can／may／might＋原形If the client approves the design, we will start production.
第二類與現在事實相反，或未來不太可能過去式（be 動詞可用 were）would／could／might＋原形If we had more staff, we would finish faster.

表格的根據：劍橋文法的條件句頁有一張總表，把條件句分成 true（零條件，劍橋叫 real conditionals）、likely／possible（第一類）、less likely／less possible（第二類）、impossible（第三類），各自的時態與助動詞也在同一頁。出處 零條件的說法依英國文化協會：「用零條件講一般為真的事，特別是法律和規則」（We use the zero conditional to talk about things that are generally true, especially for laws and rules.）。出處

換個角度，把「真的／假的」和「現在／過去」排成兩乘兩：

真的（事實，或真的有可能）假的（想像的、跟事實相反）
現在、未來零條件、第一類：If it rains tomorrow, we will move the event indoors.第二類：If I were the manager, I would change the schedule.（我不是經理）
過去過去的事實：If my father had a day off, we always went to see my granddad.（劍橋：每次發生都這樣）第三類：If we had known, we would have called you.（我們當時不知道）

左下那格的例句出自劍橋的 real conditionals：過去的情況可以兩邊都用過去式（the past simple or past continuous in both clauses for past situations）。出處

為什麼「現在」要用過去式：劍橋：第二類用過去式「是表示跟現實有距離，不是表示過去的時間」（We use a past form in the conditional clause to indicate a distance from reality, rather than indicating past time.）。出處 所以條件句的時態要「往過去推一格」：現在的假設用過去式，過去的假設用過去完成式。

時態往過去推一格＝假的：現在的假設用過去式，過去的假設用 had＋過去分詞。

兩段的順序與逗號：if 子句通常在前，也可以放後面；放前面時書面上一般加逗號，放後面一般不加（a comma is normally used in writing／a comma is not normally used in writing）。出處

這課的圖怎麼看：沿用時間軸，實心古銅點＝真的會發生或真的有可能發生的事；虛線空心圓＝想像的、跟事實相反的事；灰色細弧線箭頭＝「如果……就……」，從條件指到結果（不是時態課那種一路算到參考點的古銅箭頭）；左上角的灰藍小字寫實際的事實。

If the weather had been better, we would have held the event outdoors. 實際上那天的天氣怎麼樣？

  • 天氣很好
  • 天氣不好
  • 還不知道
  • 明天才會知道

had been＋would have held 是第三類，跟過去事實相反：「如果天氣好就會辦在戶外」，表示實際上天氣不好、活動辦在室內。

If we had more staff, we could finish the project faster. 這句在說什麼？

  • 過去人手不夠
  • 未來一定會加人
  • 這是一般的規則
  • 現在人手不夠

if＋過去式（had）、主要子句 could＋原形，是第二類，跟現在的事實相反：現在其實沒有更多人手。過去式在這裡不代表過去的時間。

If the client approves the design, we will start production. 說話的人覺得客戶核准的可能性如何？

  • 有可能核准
  • 已經核准了
  • 不太可能核准
  • 已經拒絕了

if＋現在式、主要子句 will，是第一類：說話的人覺得這件事真的有可能發生。

下面哪一句是零條件（一般事實或規則）？

  • If the invoice is paid tomorrow, we will ship the goods.
  • If the invoice were paid, we would ship the goods.
  • If an invoice is not paid within 30 days, the system sends a reminder.
  • If the invoice had been paid, we would have shipped the goods.

零條件兩邊都用現在式，講每次都這樣的規則：發票 30 天沒付，系統就寄提醒。If the invoice is paid tomorrow, we will ship… 是第一類；If the invoice were paid, we would ship… 是第二類；If the invoice had been paid, we would have shipped… 是第三類。

真的會發生，零條件與第一類

零條件與第一類：if＋現在式

零條件：英國文化協會說結構是「if／when＋現在簡單式，主要子句也是現在簡單式」（if/when + present simple >> present simple），例子 If I drink too much coffee, I can't sleep at night.。出處

第一類：劍橋：「用第一類條件句談想像中的未來情況的結果，而且相信這個情況滿有可能發生」（We use the first conditional to talk about the result of an imagined future situation, when we believe the imagined situation is quite likely），例子 If the taxi doesn't come soon, I'll drive you myself.。if 子句用現在簡單式，「助動詞放在主要子句，不放在條件子句」（We use the modal verb in the main clause, not in the conditional clause），不說 If a lawyer will read the document…。出處

這一點〈完成進行式、未來的各種說法與時態總整理〉講過：if、unless、when、as soon as 這類時間與條件子句講未來時用現在式，will 只放主要子句；主要子句也可以是 can、might、be going to，或是 please… 這種祈使句。這裡不重講，直接練。

if 子句偶爾也看得到 will 或 would，但意思不同：劍橋說這時是「願意做某事」或「指後來的結果」（with the meaning of 'being willing to do something', or to refer to later results），例如 If you would all stop shouting, I will try and explain the situation!。出處 一般講「如果發生某事」，if 子句用現在式。

與現在事實相反，或不太可能

第二類：if＋過去式，would＋原形；If I were

劍橋：「用第二類條件句談現在或未來想像情況的可能結果」（We use the second conditional to talk about the possible result of an imagined situation in the present or future），例子 If people complained, things would change.（大家現在沒抱怨）。if 子句用過去簡單式，主要子句用 should／would／might／could＋原形；而且「would 放在主要子句，不放在條件子句」，不說 If you would decide to take the exam…。出處 劍橋整理的常見錯誤也提醒：第二類的主要子句不用 shall 或 will（We don't use shall or will in the main clause in second conditional sentences），說 If you worked harder, you would earn more money.，不說 you will earn。出處

If I were：英國文化協會：if 後面接 be 動詞時，「說 if I were、if he were、if she were、if it were 是合文法的；不過口語也常聽到 was，尤其是 he／she」（it is grammatically correct to say if I were, if he were, if she were and if it were. However, it is also common to hear these structures with was, especially in the he/she form.）。出處 給建議的固定說法是 If I were you, I wouldn't mention it.。were 和 was 都有人用。

第一類還是第二類：同一件事兩種都能說，差別在說話的人覺得多可能。劍橋：「用第一類時，我們覺得想像的情況比用第二類時更可能發生」（When we use the first conditional, we think the imagined situation is more likely to happen than when we use the second conditional.），例如 If the flight's late, we'll miss our connection.（班機誤點滿有可能）對 If there were more buses, we would leave the car at home.（公車不太可能變多）。出處 所以做題時要找句子裡透露可能性的線索，例如 but we don't、unfortunately、it is very unlikely，或另一半子句已經給的時態。

比較正式、覺得不太可能的事，還可以說 if＋were to：If the Prime Minister were to resign, there would have to be a general election within 30 days.。出處

與過去事實相反

第三類：if＋had＋過去分詞，would have＋過去分詞

劍橋：「想像一個不同的過去——某件事其實發生了或沒發生——並想像不同的結果時，用第三類條件句」（We use the third conditional when we imagine a different past, where something did or did not happen, and we imagine a different result），例子 If I had played better, I would have won.（我沒打好，也沒贏）。if 子句用過去完成式（had＋過去分詞），主要子句用 should／would／might／could＋have＋過去分詞。出處

would have 只放主要子句：劍橋：「would have＋過去分詞用在主要子句，不用在條件子句」（We use would have + -ed in the main clause, not in the conditional clause），不說 If he would have stayed…；並補充「口語有人這樣說，但很多人認為是錯的」（People do sometimes use the form with would have in informal speaking, but many speakers consider it incorrect.）。出處 常見錯誤頁的例子：說 If the weather hadn't been so bad, I could have gone to meet them.，不說 If the weather would not have been so bad。出處

接〈助動詞〉那課：could have＋過去分詞是「本來可以、但沒做」，劍橋也用它講「過去其實有可能、但沒發生的事」（I could have been a lawyer.）。出處 第三類的主要子句就是把這個意思加上 if 條件：If we had left ten minutes earlier, we could have caught the flight.（本來趕得上，但沒趕上）。

縮寫 'd 要看位置：if 子句裡的 'd 是 had（英國文化協會的 If we'd moved to Scotland when I was a child…）出處；主要子句 I'd have… 的 'd 是 would（劍橋改寫 but for 的例句時寫成 if it weren't for the traffic, I'd have been here an hour ago）。出處

過去的條件，現在的結果

混合條件句：If＋had＋過去分詞，would＋原形（now）

過去發生或沒發生的事，結果常常延續到現在。劍橋：「用 if＋過去完成式、主要子句用 would，可以強調這一點」（We can emphasise this by using if with a past perfect verb, and would in the main clause.），例子 If I hadn't met Charles, I wouldn't be here now.（我遇見了 Charles，所以現在在這裡）。出處

英國文化協會把混合條件句分成兩種：

  • 過去的條件、現在的結果：If I hadn't got the job in Tokyo, I wouldn't be with my current partner.，結構是 If＋過去完成式，would＋原形（If + past perfect >> would + infinitive）。
  • 現在的條件、過去的結果：It's really important. If it wasn't, I wouldn't have called you on your holiday.，結構是 If＋過去簡單式，would have＋過去分詞（If + past simple >> would have + past participle）。出處

判斷方法：兩半各自看時間。if 子句有 last year、five years ago 這類過去的時間、主要子句有 now、today、still，就是「過去的條件、現在的結果」這一種：if 那半用 had＋過去分詞，主要子句用 would＋原形。

職場例句：

  • If we had hired more staff last year, we wouldn't be so busy now.（去年多請人的話，現在就不會這麼忙。）
  • If Ms. Park hadn't moved to Singapore, she would still be working in our Taipei office.（朴小姐沒調去新加坡的話，現在還會在台北辦公室。）
  • If our company had invested in solar panels ten years ago, our electricity bills would be much lower today.（十年前裝太陽能板的話，現在電費會低很多。）
  • If Ken weren't so careful, he wouldn't have noticed the error in the contract.（要不是 Ken 這麼細心，他不會發現合約的錯。）現在的條件、過去的結果

If we had hired more staff last year, we ______ so busy now.

  • won't be
  • weren't
  • wouldn't be
  • hadn't been

if 子句是去年的事（had hired），結果是 now：混合條件句，主要子句用 would＋原形 wouldn't be。weren't、hadn't been 不能當主要子句的結果；won't be 把它當成真的未來。

If Ms. Park hadn't accepted the job in Singapore, she ______ in our Taipei office today.

  • would still be working
  • will still be working
  • had still worked
  • still worked

過去的條件（hadn't accepted）、今天的結果：would＋原形，這裡是進行式 would still be working。will still be working 把它當成真的會發生，配不上跟事實相反的 hadn't accepted；had still worked、still worked 不能當這裡的結果。

If I ______ the instructions more carefully yesterday, I wouldn't have to redo the whole report now.

  • would read
  • will read
  • had read
  • have read

yesterday 是過去、跟事實相反（昨天沒看仔細），if 子句用 had read；結果在 now，所以主要子句是 wouldn't have to。would、will 不放在 if 子句。

He ______ the regional manager now if he had finished his MBA five years ago.

  • will be
  • is
  • had been
  • would be

條件在五年前（had finished），結果在 now：would be。is、will be 把它當成事實。

If Ken weren't such a careful reader, he ______ the error in the contract last week.

  • wouldn't have noticed
  • won't notice
  • wouldn't have been noticed
  • hadn't noticed

另一種混合條件句：現在的條件（Ken 一向細心，weren't 跟現在事實相反）、過去的結果（last week）：would have＋過去分詞 wouldn't have noticed。wouldn't have been noticed 是被動，後面卻還有受詞 the error；won't notice 是未來；hadn't noticed 不能當主要子句的結果。

If our company had invested in solar panels ten years ago, our electricity bills ______ much lower today.

  • will be
  • would be
  • were
  • had been

過去的條件（ten years ago）、今天的結果：would be。were、had been 不能當這裡的結果；will be 把它當成真的。

書信常見，省略 if 的倒裝

Should you…、Were I…、Had we known…

英國文化協會：條件句也可以不用 if，改用倒裝（把主詞和助動詞的位置對調），「這會讓句子更正式」（This makes the sentence more formal.）；第一類、第二類、第三類都能這樣做。出處 倒裝的其他句型在〈倒裝、省略與多益文法題解題順序〉；這裡先把條件句的三種講清楚。

類型怎麼改if 版倒裝版
第一類拿掉 if，用 Should＋主詞＋原形If you have any questions, …Should you have any questions, …
第二類拿掉 if，用 Were＋主詞＋to 不定詞；be 動詞直接換成 WereIf the company moved, …／If I were in your position, …Were the company to move, …／Were I in your position, …
第三類拿掉 if，把 had 搬到主詞前面If we had known, …Had we known, …
  • Should：英國文化協會：「把 if 換成助動詞 should，動詞改回原形。這讓情況顯得比較不可能一點，常用來客氣地請求或提供協助」（To invert first conditional sentences, we replace if with the auxiliary verb should and change the verb into the infinitive. This makes the situation seem a little less likely. It is often used to make a polite request or offer.），例子 Should you have any questions, I will be happy to help.。出處 劍橋的例子也是商業書信的口吻：Should you wish to cancel your order, please contact our customer service department…。出處
  • Were：「把 if 換成 were，動詞改成 to 不定詞」（we replace if with were and change the verb form to to + infinitive）：Were the Sun to disappear, Earth would no longer be able to support life.；原本就是 be 動詞時，「不需要不定詞，直接把 be 換成 were 再倒裝」（We just replace the existing form of be with were, and invert the subject and verb.）：Were California a country, it would be one of the world's largest economies.。出處
  • Had：「拿掉 if，把主詞和助動詞 had 對調」（we remove if and invert the subject and the auxiliary verb had）：Had we lost that match, it would've been a disaster.。出處
  • 否定：not 放在主詞後面（To make negative inverted conditionals, we put not after the subject.）：Should you not consent…、Had I not been busy this morning, I would have attended the meeting.，not 跟在主詞後面。出處

Should you＋原形（第一類）、Were＋主詞＋to 不定詞／Were I（第二類）、Had＋主詞＋過去分詞（第三類）。

多益的書信、公告常用 Should you have any questions, please… 這類句子收尾。題目常見的出法是空格放在句首、選項是 Should／Had／Were／If 這類字：先看主詞後面接什麼（原形 → Should；過去分詞 → Had；to 不定詞，或者主詞後面沒有動詞、直接接名詞、形容詞或 in your position 這類片語 → Were），再看主要子句的時態對不對得上。

職場例句：

  • Should you need further information, please visit our website.（如需更多資訊，請上我們的網站。）
  • Should the meeting room be unavailable, we will hold the session online.（會議室若沒空，就改線上進行。）
  • Were I in your position, I would accept the offer.（我若是你，會接受這份工作。）
  • Were the company to relocate its headquarters, many employees would have to move.（公司若遷總部，很多員工得搬家。）
  • Had we known about the traffic, we would have taken the train.（早知道會塞車，我們就搭火車了。）
  • Had the manager not approved the budget, the project would have been cancelled.（經理當初沒核准預算的話，專案就取消了。）

______ you have any questions about your order, please contact our customer service team.

  • Should
  • Had
  • Were
  • Would

後面是原形 have、主要子句是祈使句，第一類的倒裝：Should you have…（＝If you have…）。Had 後面要過去分詞；Were 後面要 to 不定詞；Would you have… 會變成問句。

Should you ______ to change your reservation, please call us at least 24 hours in advance.

  • wished
  • wishing
  • wish
  • to wish

Should＋主詞＋原形：Should you wish。should 是助動詞，後面接原形。

______ we known about the traffic, we would have taken the train instead.

  • Should
  • Had
  • Were
  • Did

後面是過去分詞 known、主要子句是 would have taken，第三類的倒裝：Had we known（＝If we had known）。

______ I in your position, I would accept the offer without hesitation.

  • Had
  • Should
  • Did
  • Were

原句是 If I were in your position，be 動詞直接換成 Were 再倒裝：Were I in your position。Had、Should、Did 後面都缺動詞。

Had the shipment arrived on time, we ______ the order to the client yesterday.

  • will deliver
  • would have delivered
  • delivered
  • would have been delivered

Had the shipment arrived 是第三類的倒裝（＝If the shipment had arrived），結果在 yesterday：would have delivered。would have been delivered 是被動，但送貨的是 we，後面還有受詞 the order；will deliver、delivered 都把它當成真的。

Were the company ______ its headquarters, many employees would have to move.

  • to relocate
  • relocate
  • relocated
  • relocating

第二類的倒裝（不是 be 動詞時）：Were＋主詞＋to 不定詞，to relocate。

______ the budget, the project would have been cancelled.

  • Hadn't the manager approved
  • Should the manager not approve
  • Had the manager not approved
  • The manager had not approved

第三類倒裝的否定：not 放在主詞後面，Had the manager not approved。Should 的倒裝是第一類，對不上 would have been；The manager had not approved 是完整的句子，跟後面的句子之間少了連接詞。

Should the main conference room ______ unavailable, we will hold the training session online.

  • is
  • being
  • been
  • be

Should＋主詞＋原形：be 動詞的原形是 be。

不用 if 也能講條件

unless、provided that、otherwise、without、but for

unless（除非）、as long as 與 provided that（只要）、in case（以防萬一）的意思在〈連接詞與連接副詞〉，這裡只補跟條件句時態有關的部分，再加上 otherwise、without、but for。

  • unless 不用在已經不可能的條件：劍橋：「不可能的條件不用 unless」（We don't use unless for impossible conditions），說 If the government had not raised food prices, there would not have been so many protests.，不說 Unless the government had raised food prices…；unless 也不跟 if 連用（unless if）。出處 所以第三類（跟過去事實相反）用 if…not，不用 unless。
  • as long as、provided (that)、providing (that)、on condition that：劍橋說這類說法用來「加上特定的條件或設限制」（impose specific conditions or set limits on a situation）；providing 在口語比較常見，provided 比較正式、多用在書面。出處 as long as 後面講未來時用現在簡單式（We always use the present simple to refer to the future after as long as），例子 You are allowed to go as long as you let us know when you arrive.。出處
  • otherwise、or（不然）：「我們常用 or 和 otherwise 表示條件的意思」（We often use or and otherwise with conditional meanings）：We'd better send it express, otherwise it'll take days.（＝If we do not send it express, it will take days.）。出處 otherwise 跟 unless、if 不同：它後面接的是「不然會怎樣」的結果，不是條件。劍橋辭典的例子是第三類：They had to leave early, otherwise the children would have been up too late.。出處
  • without＋名詞／-ing：「without＋-ing 也可以表示『如果某人沒做某事』」（Without + -ing form can also mean 'if someone does not do something'）：I couldn't get the picture out of the frame without breaking the glass.。出處 接名詞也常配第三類的主要子句，劍橋辭典：Thanks for your help – I couldn't have done it without you.。出處
  • but for＋名詞：「but for 用來帶出某件事沒發生的原因」（But for is used to introduce the reason why something didn't happen）：But for the traffic, I would have been here an hour ago.，劍橋把它改寫成 if it weren't for the traffic。出處

without／but for＋名詞＝「要不是……」，主要子句照樣用 would（have）。

Visitors may not enter the laboratory ______ they are accompanied by a member of staff.

  • provided that
  • unless
  • in case
  • otherwise

「除非有員工陪同，否則訪客不得進入實驗室」：unless（＝if…not）。provided that 會變成「只要有員工陪同就不准進」，意思反了；in case（以防萬一）不通；otherwise 不能直接帶出子句。

Late registrations for the workshop will be accepted ______ seats are still available.

  • provided that
  • unless
  • otherwise
  • in case

「只要還有空位，就接受逾期報名」：provided that 加上一個條件。unless 會變成「還有空位反而不收逾期報名」，意思相反；in case 是「以防萬一」；otherwise 不能直接帶出子句。

Please submit your expense report by noon; ______, it will not be processed until next week.

  • unless
  • provided
  • otherwise
  • in case

分號後面接「不然的話」：otherwise（＝if you do not submit it by noon）。unless、provided、in case 後面要接子句，不能這樣單獨加逗號。

______ your help, we could not have finished the project on time.

  • Unless
  • Without
  • Otherwise
  • Provided

your help 是名詞，前面要介系詞：Without your help（要不是有你幫忙），主要子句是第三類的 could not have finished。Unless、Provided 後面要接子句。

______ the heavy snow, the conference would have started on time.

  • Unless
  • Otherwise
  • Provided that
  • But for

But for＋名詞：要不是大雪，會議就準時開始了。Unless、Provided that 後面要接子句；Otherwise 不接名詞。

下面哪一句是錯的？

  • Unless we had found a new supplier, the factory would have stopped production.
  • If we hadn't found a new supplier, the factory would have stopped production.
  • We will miss the deadline unless we hire more staff.
  • Unless the price drops, we will keep our current supplier.

已經找到新供應商了，「沒找到」是不可能的條件，劍橋說這種情況不用 unless，要用 if…not：If we hadn't found…。另外兩句 unless 講未來可能的事，正確。

You can borrow the company car ______ you return it with a full tank.

  • unless
  • as long as
  • in case
  • otherwise

「只要加滿油還回來，就可以借」：as long as。unless 意思相反；in case 是「以防萬一」。

希望事情不是這樣

wish、if only、It's time：時態一樣往過去推一格

劍橋：wish 後面的 that 子句「用的動詞形式跟 if 條件子句很像：用過去式講現在和未來」（The verb forms we use in that-clauses after wish are similar to the verb forms in conditional clauses after if. We use a past verb form for present and future meanings.），例如 I wish we had a bigger car.；「希望過去不一樣時，wish 後面用過去完成式」（When we wish something about the past, we use the past perfect after wish）：I wish I hadn't said that.。出處

希望哪個時間不一樣wish／if only 後面例句
現在過去式（could＋原形也可以）I wish I had more time.（其實沒有）
過去had＋過去分詞I wish I had read the contract more carefully.（當時沒仔細看）
別人的行為讓人不滿would＋原形I wish you'd stop making so much noise!
  • wish＋would：英國文化協會：「用 wish＋would(n't) 表示對某人或某事做或不做的事感到不滿」（We can use wish + would(n't) to show that we are annoyed with what someone or something does or doesn't do.）出處；would 用在說話的人希望「別人或別的事」改變的時候（Would is used when the speaker wants someone or something else to change.）。出處
  • 對未來的祝福用 hope，不用 wish：劍橋：「希望未來某事發生、或希望過去某事已經發生，用 hope 不用 wish」（We use hope, not wish, when we want something to happen in the future or when we want something to have happened in the past），說 I hope the weather's fine tomorrow.，不說 I wish the weather's fine tomorrow.。出處 例外是祝福的固定句型 wish＋人＋名詞：I wish you success in your new job.。出處
  • if only：「意思跟 I wish 一樣，但更強烈」（It means the same as I wish but is stronger.）；現在用過去式（If only he knew the truth.，不說 If only he knows），過去用過去完成式（If only he had listened…），希望別人改變用 would。出處
  • It's time＋過去式：劍橋：「It's time…用過去式講現在這一刻」（We use the expression it's time … to refer to the present moment with a past verb form）：It's eleven-thirty. It's time I went to bed.，不說 It's time I go to bed.。出處 英國文化協會補充 It's high time，意思是「早該做了」：It's time we took responsibility for our planet.。出處

wish／if only／It's time＋過去式＝現在不是這樣；wish／if only＋had＋過去分詞＝過去不是這樣。

I wish I ______ more time to prepare for tomorrow's presentation.

  • have
  • had
  • will have
  • having

希望「現在」有更多時間（其實沒有），wish 後面用過去式 had。have、will have 是劍橋說 wish 後面不用的形式。

I wish I ______ the client's e-mail before yesterday's meeting.

  • have read
  • would read
  • will read
  • had read

後悔「過去」沒看，wish＋過去完成式 had read。

If only we ______ the tickets earlier — now they're all sold out.

  • had booked
  • have booked
  • will book
  • would book

票已經賣完，後悔過去沒早點訂：If only＋過去完成式 had booked。would book 是希望別人或未來改變，跟「已經賣完」對不上。

It's already the end of the quarter. It's time we ______ a decision about the new office.

  • make
  • will make
  • made
  • making

It's time＋主詞＋過去式，講的是現在：It's time we made a decision。劍橋把 It's time I go 列為錯誤。

I ______ you have a safe and pleasant trip to Osaka next week.

  • hope
  • wish
  • wished
  • hoping

希望未來的事順利，用 hope。wish 後面接子句時是講「不是事實」的事，對未來的祝福不用 wish＋子句。

I wish my colleague ______ playing music so loudly in the office. It's very distracting.

  • stops
  • will stop
  • has stopped
  • would stop

對同事的行為不滿、希望他改變：wish＋would＋原形，would stop。

The sales figures are disappointing. If only our new product ______ more popular with young customers.

  • is
  • were
  • will be
  • has been

希望「現在」不一樣（產品現在不受歡迎），if only＋過去式，be 動詞用 were。劍橋把 if only＋現在式（If only he knows）列為錯誤。

看一半，判斷另一半

綜合練習

做題順序：先看題目給了哪一半。給了 if 子句，就看它的時態（現在式、過去式、had＋過去分詞）決定主要子句；給了主要子句（will、would、would have），就倒回去決定 if 子句。最後找句子裡的時間詞（tomorrow、yesterday、now）和事實線索（but we don't、unfortunately）確認。

If the bank ______ our loan application next week, we will open a new branch in the spring.

  • approved
  • approves
  • had approved
  • approving

主要子句是 will open、時間是 next week，第一類：if 子句用現在式 approves。

If our sales team ______ harder last quarter, we would have reached our target.

  • has worked
  • would work
  • had worked
  • works

主要子句是 would have reached、時間是 last quarter，第三類：if 子句用 had worked。

______ you require any further assistance, please do not hesitate to contact me.

  • Were
  • Had
  • Should
  • Unless

後面是原形 require、主要子句是祈使句，第一類的倒裝：Should you require…。Unless you require… 是「如果你不需要協助，請聯絡我」，意思反了。

If I were the department manager, I ______ the weekly meeting to Friday afternoon.

  • would move
  • will move
  • move
  • had moved

if 子句是 If I were（我不是經理），第二類：主要子句用 would＋原形 would move。

We would have saved a lot of money if we ______ the flight tickets in advance.

  • buy
  • would buy
  • have bought
  • had bought

主要子句是 would have saved，第三類：if 子句用 had bought。would 不放在 if 子句。

重點整理

  • 零條件：if＋現在式，主要子句現在式（規則、每次都這樣）；第一類：if＋現在式，主要子句 will／can／may＋原形（未來真的有可能）。will、would 一般不放在 if 子句。
  • 第二類：if＋過去式（be 用 were），主要子句 would／could／might＋原形，講現在的假設或不太可能的未來；過去式在這裡表示「跟現實有距離」。
  • 第三類：if＋had＋過去分詞，主要子句 would／could／might have＋過去分詞，講跟過去事實相反；would have 只放主要子句。
  • 混合條件句：過去的條件、現在的結果用 if＋had＋過去分詞，主要子句 would＋原形（看 now、today、still）。
  • 省略 if 的倒裝比較正式：Should you＋原形（第一類）、Were＋主詞＋to 不定詞／Were I（第二類）、Had＋主詞＋過去分詞（第三類）；否定把 not 放在主詞後面。
  • unless 不用在已經不可能的條件；without／but for＋名詞＝要不是；otherwise＝不然；wish、if only、It's time 後面時態往過去推一格，對未來的期望用 hope。
