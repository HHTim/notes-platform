資產與圖示

靜態資產放哪裡

圖片、字型等靜態資產放在專案設定指定的資產目錄。Angular 18 起，新專案的預設資產目錄是與 src/ 同層的 public/（angular.json 的 assets 設定指向它）；src/assets 是舊版預設，既有專案仍可沿用或在 angular.json 自行設定出處。改了 angular.json 的建置設定後，記得重新啟動開發伺服器才會生效。

圖示套件也一樣：只註冊真正用到的圖示，像出門只帶會用到的工具，避免把整套圖示全部打包進產出檔、讓專案越長越肥。

樣式架構

全域樣式與元件樣式各司其職

全域樣式（styles.css 或 styles.less）放色彩變數、文字規格、間距與重設規則；元件樣式只描述該元件自己。預處理器（SCSS 或 Less，先寫變數與巢狀再編譯成 CSS 的工具）在建立專案時選定最省事，之後也能改檔名並同步修改 angular.json 的 styles 設定。

:root {
  --color-bg: #ffffff;
  --color-text: #202124;
}

:root[data-theme='dark'] {
  --color-bg: #171717;
  --color-text: #f3f3f3;
}

body {
  background: var(--color-bg);
  color: var(--color-text);
}

用第三方 UI 套件（如 Ant Design）時，還要照套件文件載入它的基礎樣式；把基礎樣式拿掉，元件功能還在、外觀卻會整個失靈。

樣式封裝

為何父元件的 CSS 套不到子元件

Angular 預設做檢視封裝（View Encapsulation）：編譯時替每個元件的元素加上專屬的屬性選擇器，像替每間房間的油漆貼上房號，元件樣式就不會外洩污染別的區域。這也是為什麼在父元件寫 p { color: red }，子元件的 <p> 不會變紅。

:host 用來選取元件自己的宿主元素（元件標籤本身，例如 <app-card>）：

:host {
  display: block;
}

:host .title {
  font-weight: 700;
}

::ng-deep 會拆掉封裝、讓選擇器穿透到子元件，Angular 官方強烈不建議新程式使用，保留它只是為了回溯相容出處。要客製第三方元件的外觀，優先順序是：套件提供的主題 API、CSS 變數、可設定的 class，再來才是範圍收窄的全域樣式。

偏好保存

localStorage、sessionStorage、Cookie 與 Session

HTTP 本身無狀態，指的是伺服器不記得上一個請求是誰發的，而不是每次都要重新建立連線出處。要讓「使用者選的主題」或「登入狀態」留下來，得靠瀏覽器端或伺服器端的保存機制：

機制生命週期與範圍適合用途
localStorage同源下持續保存，同源的各分頁都讀得到主題、語言等非敏感偏好
sessionStorage只限單一分頁的工作階段，關閉即消失單次流程的暫存狀態
Cookie可設過期時間，符合規則時隨每次 HTTP 請求送出由伺服器讀取的識別資訊（單顆約 4KB）
伺服器 Session資料放伺服器，瀏覽器通常只拿一個識別碼登入狀態與敏感的工作階段資料

Web Storage（localStorage 與 sessionStorage 的統稱）只能存字串，物件要先用 JSON 轉換。敏感憑證（例如登入用的 JWT）不要只因為方便就放 localStorage出處。

主題初始化

在第一個畫面出現前套回偏好

主題存進 localStorage 之後還差一步：重新整理頁面時，要在畫面出現前把它讀回來套用，不然會先閃一下預設主題。Angular 的應用初始化機制就是做這件事。原筆記記的是對的：APP_INITIALIZER 這個舊寫法自 Angular 19 起標記為棄用，官方建議改用 provideAppInitializer（出處）：

import { provideAppInitializer, inject } from '@angular/core';

export const appConfig = {
  providers: [
    provideAppInitializer(() => {
      const theme = inject(ThemeService);
      theme.apply(localStorage.getItem('theme') ?? 'light');
    })
  ]
};

啟動流程概念上是：執行進入點 main.ts → 讀取應用設定 app.config.ts → 執行所有初始化函式 → 建立根元件。初始化函式回傳 Promise 或 Observable 時，Angular 會等它完成才往下走。

瀏覽器安全邊界

同源政策與 CORS

兩個網址要通訊協定、主機、埠號三者都相同才算同源（路徑不同沒關係）。localStorage 與 sessionStorage 都受同源邊界限制：別的網站讀不到你網站存的東西。CORS（跨來源資源共享）不是把同源政策關掉，而是伺服器透過回應標頭，明確允許特定來源讀取跨來源的回應。

同源＝通訊協定相同＋主機相同＋埠號相同

重點整理

  • Angular 18 起新專案的靜態資產預設放 public/；改建置設定要重啟開發伺服器。
  • 全域樣式管變數與規格，元件樣式管自己；檢視封裝靠編譯期的屬性選擇器隔離。
  • 客製第三方元件優先用正式主題 API；::ng-deep 官方強烈不建議新用。
  • 主題偏好放 localStorage，啟動時用 provideAppInitializer 套回（APP_INITIALIZER 自 v19 起棄用）。
  • 同源＝協定＋主機＋埠號都相同；CORS 是伺服器開白名單，不是前端片面放行。
